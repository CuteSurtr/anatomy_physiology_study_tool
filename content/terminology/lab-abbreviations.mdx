Reference ranges vary by lab and population. The numbers below are typical adult values, US conventional units.

## Complete blood count (CBC)

| Lab | Range | Notes |
|---|---|---|
| **WBC** | 4.5-11.0 × 10³/µL | Differential: neutrophils 50-70%, lymphocytes 20-40%, monocytes 2-8%, eos 1-4%, baso &lt;1% |
| **RBC** | M 4.5-5.9, F 4.0-5.2 × 10⁶/µL | |
| **Hgb** | M 13.5-17.5, F 12.0-16.0 g/dL | Anemia thresholds vary |
| **Hct** | M 41-53%, F 36-46% | ~3× Hgb |
| **MCV** | 80-100 fL | &lt;80 microcytic; >100 macrocytic |
| **MCH** | 27-33 pg/cell | |
| **MCHC** | 32-36 g/dL | High in spherocytosis |
| **RDW** | 11.5-14.5% | High = mixed populations (iron def + B12) |
| **Plt** | 150-400 × 10³/µL | &lt;150 = thrombocytopenia; &lt;50 → bleeding risk; &lt;20 → spontaneous |
| **Reticulocyte** | 0.5-2.5% (absolute 25-100 × 10³/µL) | Marker of marrow response |

## Anion gap

`AG = Na - (Cl + HCO₃)` - normal 8-12 mEq/L.
**Albumin-corrected**: add 2.5 × (4 - albumin) to measured gap.

**High AG** = MUDPILES:
- Methanol
- Uremia
- DKA / Alcoholic KA / Starvation KA
- Propylene glycol
- Iron, INH
- Lactic acidosis
- Ethylene glycol
- Salicylates

**Normal AG**: GI losses, RTA, drug-induced (acetazolamide, TPN, ammonium chloride).

## Liver enzymes - patterns

| Pattern | What it suggests |
|---|---|
| **AST > ALT, ratio >2** | Alcoholic hepatitis ("2× AST = SCOTCH") |
| **ALT > AST** | Viral, drug, NAFLD |
| **Marked AST/ALT (>1000)** | Acute viral, toxin, ischemia, autoimmune |
| **Mild AST/ALT** | Chronic disease - HCV, NAFLD, drug |
| **ALP elevated** | Cholestasis (also bone) - check GGT or 5'-nucleotidase to distinguish |
| **Indirect hyperbilirubinemia** | Hemolysis, Gilbert syndrome, ineffective erythropoiesis |
| **Direct hyperbilirubinemia** | Hepatocyte damage, cholestasis (intra-/extra-hepatic) |

## Coagulation panel

| Lab | Range | Tests what |
|---|---|---|
| **PT** | 11-13 sec (varies) | Extrinsic + common (II, V, VII, X, fibrinogen) - **warfarin** target |
| **INR** | 0.8-1.2 (normal); target 2-3 for most warfarin | Standardized PT |
| **aPTT, PTT** | 25-35 sec | Intrinsic + common (XII, XI, IX, VIII, X, V, II, fibrinogen) - **heparin** target |
| **Thrombin time (TT)** | 14-19 sec | Fibrin formation; ↑ in heparin, DIC |
| **Fibrinogen** | 200-400 mg/dL | ↓ in DIC, liver failure |
| **D-dimer** | &lt;500 ng/mL (varies) | Fibrin degradation; ↑ in PE/DVT but nonspecific |
| **Platelet** | 150-400 × 10³ | (see CBC) |
| **Bleeding time** | &lt;9 min | qualitative platelet; rarely used |

## Glucose + diabetes

| Lab | Range |
|---|---|
| **Fasting glucose** | 70-100 normal; 100-125 prediabetes; ≥126 diabetes |
| **2-h OGTT** | &lt;140 normal; 140-199 prediabetes; ≥200 diabetes |
| **Random** | ≥200 + symptoms = diabetes |
| **HbA1c** | &lt;5.7% normal; 5.7-6.4 prediabetes; ≥6.5% diabetes |

## ABG (arterial blood gas)

| Parameter | Range |
|---|---|
| **pH** | 7.35-7.45 |
| **PaCO₂** | 35-45 mmHg |
| **PaO₂** | 75-100 mmHg (on room air; age-dependent) |
| **HCO₃** | 22-28 mEq/L |
| **Base excess** | -2 to +2 |
| **SaO₂** | >95% |
| **Lactate** | &lt;2 mmol/L |

**Interpretation steps**:
1. pH? Acidemia (&lt;7.35) or alkalemia (>7.45).
2. Primary cause? PaCO₂ (respiratory) vs HCO₃ (metabolic).
3. Compensation appropriate?
   - Metabolic acidosis: PaCO₂ falls by 1.2 × (24 - HCO₃); Winter formula: PaCO₂ = (1.5 × HCO₃) + 8 ± 2.
   - Metabolic alkalosis: PaCO₂ rises by 0.7 × (HCO₃ - 24).
   - Resp acidosis: acute - HCO₃ ↑ 1 per 10 ↑ PaCO₂. Chronic - HCO₃ ↑ 3-4 per 10.
   - Resp alkalosis: acute - HCO₃ ↓ 2 per 10 ↓ PaCO₂. Chronic - HCO₃ ↓ 4-5 per 10.
4. Anion gap (if metabolic acidosis).
5. Delta-delta (if multiple disorders).

| **Specific gravity** | 1.005-1.030 |

## Quick cheat - "fishbone" diagrams

The fishbone (lattice diagram) at bedside puts each value in standard position. Memorize the layout so you can read any fishbone in seconds.

```
WBC < Hgb / Hct > Plt          (CBC fishbone)

Na  | Cl  | BUN
            < Glucose
K   | CO2 | Cr
```
