## Anatomical position

The standard reference position - all directional terms assume this:
- **Standing upright**.
- **Facing forward**.
- **Arms at sides, palms facing forward**.
- **Feet flat, toes forward**.

## Directional terms (pairs)

| Term | Meaning | Example |
|---|---|---|
| **Anterior (ventral)** | Toward the front | Sternum is anterior to heart |
| **Posterior (dorsal)** | Toward the back | Spine is posterior to esophagus |
| **Superior (cranial, cephalad)** | Toward the head | Heart is superior to diaphragm |
| **Inferior (caudal)** | Toward the feet/tail | Stomach is inferior to lungs |
| **Medial** | Toward the midline | Sternum is medial to nipple |
| **Lateral** | Away from the midline | Shoulder is lateral to neck |
| **Proximal** | Closer to point of origin/trunk | Knee is proximal to ankle |
| **Distal** | Farther from origin | Fingers are distal to wrist |
| **Superficial (external)** | Toward the surface | Skin is superficial to muscle |
| **Deep (internal)** | Away from surface | Bones are deep to skin |
| **Ipsilateral** | Same side | Right hand + right foot |
| **Contralateral** | Opposite side | Left arm + right leg |
| **Bilateral** | Both sides | Bilateral kidneys |
| **Unilateral** | One side | Unilateral stroke deficit |

## Body planes

| Plane | Description | Use |
|---|---|---|
| **Sagittal** | Vertical, divides L+R | Sagittal MRI brain |
| **Midsagittal (median)** | Exactly through midline | |
| **Parasagittal** | Parallel to midsagittal, off-center | |
| **Frontal (coronal)** | Vertical, divides anterior + posterior | Frontal X-ray |
| **Transverse (horizontal, axial)** | Horizontal, divides superior + inferior | CT axial slices |
| **Oblique** | Diagonal plane | Pelvic oblique view |

Imaging conventions:
- **Axial CT/MRI**: view as if **looking up from feet** (patient's right on viewer's left).
- **Coronal**: view as if facing patient (same orientation).
- **Sagittal**: typically left-side view.

## Body positions (clinical)

| Position | Description |
|---|---|
| **Supine** | On back, face up |
| **Prone** | On stomach, face down |
| **Lateral recumbent** | On side |
| **Sims' position** | Left lateral with right knee flexed (rectal exam, enemas) |
| **Fowler's** | Sitting at 45-60° |
| **Semi-Fowler's** | Sitting at 30° |
| **High Fowler's** | 90° upright |
| **Trendelenburg** | Head down, feet up (shock historic - largely abandoned) |
| **Reverse Trendelenburg** | Feet down, head up |
| **Lithotomy** | Supine, legs in stirrups (pelvic exam, OB) |
| **Knee-chest (genupectoral)** | On knees + chest, hips elevated |
| **Decubitus (left/right lateral)** | Lying on a side |
| **Recovery (lateral)** | Side, head tilted (airway protection) |
| **Jackknife** | Prone hips flexed (rectal surgery) |
| **Modified-Fowler** | Variations of sitting elevation |

## Body regions

### Abdominal quadrants (4 quadrants)

| Quadrant | Major contents |
|---|---|
| **RUQ** | Liver, gallbladder, R kidney, head of pancreas, hepatic flexure |
| **LUQ** | Stomach, spleen, L kidney, body of pancreas, splenic flexure |
| **RLQ** | Appendix, cecum, R ovary, ileum, R ureter |
| **LLQ** | Sigmoid colon, descending colon, L ovary, L ureter |

### Abdominal regions (9 regions)

| Region | Location |
|---|---|
| **Right + Left hypochondriac** | Upper, lateral (under ribs) |
| **Epigastric** | Upper, midline |
| **Right + Left lumbar (lateral)** | Middle, lateral |
| **Umbilical** | Middle, midline |
| **Right + Left iliac (inguinal)** | Lower, lateral |
| **Hypogastric (pubic)** | Lower, midline |

### Body cavities

| Cavity | Subdivisions / contents |
|---|---|
| **Dorsal cavity** | Cranial (brain) + vertebral (spinal cord) |
| **Ventral cavity** | Thoracic + abdominopelvic |
| **Thoracic cavity** | Pleural (lungs L+R), mediastinum (heart, esophagus, trachea, great vessels) |
| **Pericardial cavity** | Heart - within mediastinum |
| **Abdominal cavity** | Stomach, intestines, liver, spleen, kidneys, etc. |
| **Pelvic cavity** | Bladder, reproductive organs, distal GI |

### Serous membranes

| Membrane | Cavity |
|---|---|
| **Pleura** | Lungs |
| **Pericardium** | Heart |
| **Peritoneum** | Abdomen |

Each has parietal (outer) + visceral (inner) layers with fluid between.

## Anatomical "rules" (memorize)

- **NAVL** (femoral triangle): Nerve, Artery, Vein, Lymphatics - lateral to medial.
- **VAN** (axillary): in costal grooves - vein, artery, nerve (top to bottom).
- "**A wise man wins on Friday**" - axilla 12 lymph node groups (anatomical reasons).

- **McBurney's point** = appendix (1/3 from ASIS to umbilicus).
- **Murphy's sign** = inspiratory arrest with RUQ palpation (cholecystitis).
- **PMI** at 5th ICS midclavicular line; lateral displacement = cardiomegaly.
