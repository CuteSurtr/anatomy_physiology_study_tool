These pairs sound or look similar but mean very different things. Misuse can be a serious clinical error.

## Anatomy

| Pair | Difference |
|---|---|
| **Ileum / Ilium** | **Ileum** (E) = third part of small intestine. **Ilium** (I) = bone of pelvis. Mnemonic: "**E**at" with the **E** (intestine). |
| **Mucus / Mucous** | **Mucus** (noun) = the substance. **Mucous** (adjective) = describing membrane. "**Mucous membrane** secretes **mucus**." |
| **Serous / Serum** | **Serous** = adjective relating to serum (fluid). **Serum** = clear fluid (e.g., blood serum). |
| **Hepatic / Hepar** | Hepatic = related to liver. Hepar = liver (Greek). |
| **Anti- / Ante-** | Anti = against (antibiotic). Ante = before (antenatal). |
| **Perineum / Peritoneum** | **Perineum** = area between anus + genitals (external). **Peritoneum** = abdominal serous membrane (internal). |
| **Pulmonary / Pulmonic** | Both refer to lungs but used differently: pulmonary embolism, pulmonic valve. |
| **Pleura / Plexus** | Pleura = lung membrane. Plexus = network of nerves/vessels. |
| **Vena cava / Vena saphena** | Cava = IVC/SVC. Saphena = leg superficial veins. |
| **Cervix (uterine) / Cervix (neck)** | Same word - context determines (cervical spine vs cervical cancer). |
| **Cilium / Stereocilium** | Cilium = motile (respiratory). Stereocilium = non-motile (vestibular hair, vas deferens). |

## Procedures

| Pair | Difference |
|---|---|
| **-ectomy / -otomy / -ostomy** | Ectomy = removal. Otomy = incise (no removal). Ostomy = create opening. |
| **Laparotomy / Laparoscopy** | Laparotomy = open abdominal surgery. Laparoscopy = scope through small ports. |
| **Tracheotomy / Tracheostomy** | Tracheotomy = the procedure. Tracheostomy = the resulting opening (more common term). |
| **Resection / Excision** | Resection = removal of part of organ. Excision = removal of lesion. |
| **Anastomosis / Anastomotic** | Anastomosis = surgical connection. Anastomotic = relating to that connection. |

## Drugs (LASA - look-alike sound-alike)

The classic dangerous pairs:

| Pair | Difference |
|---|---|
| **Hydroxyzine / Hydralazine** | Antihistamine vs vasodilator |
| **Lamictal / Lamisil** | Lamotrigine vs terbinafine |
| **Celebrex / Cerebyx / Celexa** | Celecoxib vs fosphenytoin vs citalopram |
| **Vinblastine / Vincristine** | Different chemo drugs; doses very different |
| **Toradol / Tramadol** | Ketorolac (NSAID) vs tramadol (opioid) |
| **Zantac / Xanax** | Ranitidine (withdrawn) vs alprazolam |
| **Plavix / Paxil** | Clopidogrel vs paroxetine |
| **Lasix / Losec / Losartan** | Furosemide vs omeprazole vs ARB |
| **Avandia / Coumadin** | Rosiglitazone vs warfarin |
| **Dilaudid / Demerol** | Hydromorphone vs meperidine |
| **Heparin / Hespan** | Heparin vs hetastarch |
| **Insulin units (Humalog / Humulin)** | Different formulations |
| **Hydroxychloroquine / Hydrochlorothiazide** | Anti-malarial vs thiazide |
| **Chlorpromazine / Chlorpropamide** | Antipsychotic vs sulfonylurea |
| **Methadone / Methotrexate** | Opioid vs chemo |
| **Lithium / Lasix** | Mood vs diuretic |
| **Diltiazem / Doxazosin** | CCB vs α-blocker |

## Conditions (symptom confusion)

| Pair | Difference |
|---|---|
| **Dysphagia / Dysphasia** | **Phagia** = swallowing. **Phasia** = speech. |
| **Aphasia / Apraxia / Ataxia** | Aphasia = language. Apraxia = motor planning. Ataxia = coordination. |
| **Anosmia / Anoxia** | Smell loss vs no oxygen. |
| **Anesthesia / Analgesia / Anhidrosis** | No sensation / no pain / no sweating. |
| **Hyperhidrosis / Hidradenitis** | Excess sweat / sweat gland inflammation. |
| **Hyperemia / Hyperalgesia / Hyperesthesia** | ↑ blood flow / ↑ pain / ↑ sensation. |
| **Paresis / Paralysis (plegia)** | Weakness vs total paralysis. |
| **Hemiplegia / Paraplegia / Quadriplegia** | One side / lower body / all four. |
| **Diabetes mellitus / Diabetes insipidus** | "Mellitus" = honey-sweet (high glucose). "Insipidus" = tasteless (water diabetes - ADH issue). |
| **Hematuria / Hemoptysis / Hematemesis / Hematochezia / Melena** | Blood in urine / cough / vomit / red rectal / black tarry stool. |
| **Tinnitus / Tetanus** | Ear ringing vs muscle spasm disease. |
| **Pleurisy / Pleuritic** | Pleurisy = the disease. Pleuritic = the type of pain. |
| **Cardia / Cardiac** | Cardia = part of stomach near LES. Cardiac = pertaining to heart. |

## Symptoms

| Pair | Difference |
|---|---|
| **Nausea / Anorexia** | Nausea = urge to vomit. Anorexia = lack of appetite. |
| **Vomiting / Regurgitation** | Vomiting = forceful, abdominal contractions. Regurgitation = passive return. |
| **Dyspnea / Tachypnea / Orthopnea** | Difficulty / fast / supine SOB. |
| **Stridor / Wheeze / Rhonchi / Rales (crackles)** | Stridor = upper airway. Wheeze = lower expiratory. Rhonchi = coarse (mucus). Crackles = fine (alveolar). |
| **Murmur / Bruit / Thrill** | Murmur = heart sound. Bruit = vascular. Thrill = palpable vibration. |
| **Palpate / Palpitate** | Palpate = examine by touch. Palpitate = abnormal heartbeat sensation. |
| **Affect / Effect** | Affect (verb) = to influence; (noun, psych) = emotional expression. Effect = result. |
| **Cyanosis / Cyanide** | Bluish discoloration vs poison. |
| **Edema / Effusion** | Edema = tissue swelling. Effusion = fluid in body cavity. |
| **Petechiae / Purpura / Ecchymosis** | Pinpoint / larger purple / bruise. |
| **Lethargy / Lethargic / Obtunded / Stuporous / Comatose** | Decreasing levels of consciousness. |

## Lab values

| Pair | Difference |
|---|---|
| **Hypoglycemia / Hyperglycemia** | Low vs high glucose. |
| **Hypokalemia / Hyperkalemia** | Low vs high K. |
| **Hyponatremia / Hypernatremia** | Low vs high Na. |
| **Hypocalcemia / Hypercalcemia** | Low vs high Ca. |
| **Hyperthyroid / Hypothyroid** | Too much vs too little thyroid hormone. |
| **Tachycardia / Bradycardia** | Fast vs slow heart. |
| **Tachypnea / Bradypnea** | Fast vs slow breathing. |
| **Acidemia / Alkalemia / Acidosis / Alkalosis** | -**emia** = blood pH. -**osis** = the process causing it. |

## Hormones / endocrine

| Pair | Difference |
|---|---|
| **Cortisol / Cortisone** | Cortisol = active. Cortisone = inactive (converted to cortisol). |
| **Aldosterone / Aldolase** | Mineralocorticoid vs enzyme (muscle marker). |
| **Adrenaline / Noradrenaline** | Epinephrine vs norepinephrine. |
| **Estradiol / Estrone / Estriol** | E2 (premenopause) / E1 (post) / E3 (pregnancy). |
| **Progesterone / Progestin** | Natural hormone vs synthetic analog. |
| **Vasopressin / Vasopressor** | ADH vs class of pressor drugs. |
| **Calcitonin / Calcitriol** | Thyroid C-cell hormone vs active vit D. |

## Genetics

| Pair | Difference |
|---|---|
| **Genotype / Phenotype** | DNA vs observable. |
| **Homozygous / Heterozygous** | Same / different alleles. |
| **Heterozygous / Hemizygous** | Different alleles / only one copy (X-linked males). |
| **Dominant / Recessive** | Expressed in heterozygote / needs both copies. |
| **Penetrance / Expressivity** | % showing trait / how severely. |
| **Mosaicism / Chimera** | Same person multiple cell lines / fusion of 2 zygotes. |

## Imaging

| Pair | Difference |
|---|---|
| **CT / MRI** | X-ray cross-section vs magnetic. |
| **MRI / MRA / MRV / MRCP** | Plain MR / arteries / veins / biliary. |
| **Echo / EKG / EEG / EMG** | Heart structure / heart rhythm / brain / muscle. |
| **AP / PA / LAT** | Different X-ray projections. |

## Microbiology

| Pair | Difference |
|---|---|
| **Bacteremia / Sepsis** | Bacteria in blood / clinical syndrome. |
| **Septic / Septicemia** | Adjective / older term for sepsis. |
| **Sterile / Aseptic** | No organisms / free from contamination. |
| **Antiseptic / Disinfectant** | On living tissue / on surfaces. |
| **Antibiotic / Antimicrobial** | Specifically against bacteria vs broader (incl. viruses, fungi). |
| **Bactericidal / Bacteriostatic** | Kills / inhibits growth. |
| **Aerobic / Anaerobic** | Needs O2 / doesn't (or killed by). |
| **Pathogen / Commensal / Symbiont** | Causes disease / lives on host harmlessly / mutualistic. |

## Pregnancy

| Pair | Difference |
|---|---|
| **Gravida / Para** | Number of pregnancies / births. |
| **Gravida / Multigravida / Nulligravida** | Pregnant once / multiple / never. |
| **Primipara / Multipara / Nullipara** | 1 birth / multiple / none. |
| **Antepartum / Intrapartum / Postpartum** | Before / during / after labor. |
| **Embryo / Fetus** | Up to week 8 / after week 8. |

## Death & dying

| Pair | Difference |
|---|---|
| **Necrosis / Apoptosis** | Unprogrammed cell death (inflammation) / programmed (no inflammation). |
| **Autolysis / Autopsy** | Self-digestion of dead tissue / postmortem exam. |
| **Postmortem / Ante-mortem** | After / before death. |

## Common writing errors (intra- vs inter-)

| Pair | Examples |
|---|---|
| **Intra-** (within) | Intravenous, intracerebral, intra-abdominal |
| **Inter-** (between) | Intercostal, intervertebral, interphalangeal |
| **Intro-** (into) | Introducer, introduction |

Mnemonic: "**Intra** keeps it inside" / "**Inter**course is between people."

## Per- vs peri-

| Pair | Examples |
|---|---|
| **Per-** (through) | Percutaneous (through skin), perforation (hole through) |
| **Peri-** (around) | Pericardium (around heart), periapical (around tooth tip) |

Mnemonic: **peri**meter = around. **per**meate = through.

## Numbers in names

| Confusion | Examples |
|---|---|
| **Vitamin B6 (pyridoxine) vs B12 (cobalamin)** | Different deficiencies, different treatments. |
| **Type 1 vs Type 2 DM** | Autoimmune (no insulin) vs insulin resistance. |
| **HSV-1 vs HSV-2** | Oral vs genital (mostly; can switch). |

## Last names that look identical

| Confusion | Clarification |
|---|---|
| **Crohn vs Cohn / Cohn vs Conn** | Crohn = GI doc. Conn = aldosteronism. |
| **Albright (multiple syndromes)** | McCune-Albright; Albright hereditary osteodystrophy; etc. |
| **Down vs Down's** | Same; possessive form falling out of favor. |
