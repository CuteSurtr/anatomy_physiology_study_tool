Suffixes tell you **what is happening** to the root: a procedure, a disease, an inflammation, an opening, a study.

## Conditions + diseases

| Suffix | Meaning | Examples |
|---|---|---|
| **-itis** | Inflammation | appendicitis, otitis, dermatitis, arthritis, hepatitis, nephritis |
| **-osis** | Abnormal condition (often chronic, non-inflammatory) | scoliosis, halitosis, cyanosis, fibrosis |
| **-pathy** | Disease (general) | neuropathy, retinopathy, cardiomyopathy |
| **-iasis** | Condition, presence of | cholelithiasis (gallstones), nephrolithiasis (kidney stones) |
| **-ism** | State, condition, theory | hyperthyroidism, embolism, alcoholism |
| **-emia** | Blood condition | anemia, leukemia, hyperkalemia, hypoglycemia, septicemia |
| **-uria** | Urine condition | polyuria, hematuria, oliguria, glycosuria, proteinuria |
| **-rrhea** | Flow, discharge | diarrhea, rhinorrhea, otorrhea, gonorrhea |
| **-rrhage, -rrhagia** | Bursting forth (bleeding) | hemorrhage, menorrhagia |
| **-rrhexis** | Rupture | cardiorrhexis |
| **-rrhaphy** | Suture | herniorrhaphy |
| **-edema** | Swelling | lymphedema, papilledema, angioedema |
| **-plasia** | Formation, growth | hyperplasia, dysplasia, aplasia |
| **-plasm** | Growth, formation | neoplasm, cytoplasm, protoplasm |
| **-trophy** | Development, growth | hypertrophy, atrophy, dystrophy |
| **-stenosis** | Narrowing | aortic stenosis, spinal stenosis |
| **-sclerosis** | Hardening | atherosclerosis, multiple sclerosis |
| **-malacia** | Softening | osteomalacia, chondromalacia |
| **-megaly** | Enlargement | hepatomegaly, splenomegaly, cardiomegaly, acromegaly |
| **-cele** | Hernia, swelling, cavity | hydrocele, varicocele, rectocele, cystocele |
| **-ptosis** | Drooping, falling | nephroptosis, blepharoptosis, gastroptosis |
| **-spasm** | Involuntary contraction | bronchospasm, blepharospasm |
| **-lysis** | Breakdown, destruction | hemolysis, dialysis, paralysis |
| **-penia** | Deficiency, lack | neutropenia, thrombocytopenia, osteopenia, leukopenia |

## Procedures + surgery

| Suffix | Meaning | Examples |
|---|---|---|
| **-tomy** | Incision (cutting into) | tracheotomy, laparotomy, craniotomy |
| **-ectomy** | Surgical removal | appendectomy, mastectomy, hysterectomy, cholecystectomy |
| **-stomy** | Creating an opening | colostomy, tracheostomy, gastrostomy, ileostomy |
| **-pexy** | Surgical fixation | nephropexy, orchidopexy, mastopexy |
| **-plasty** | Surgical repair / reconstruction | rhinoplasty, angioplasty, arthroplasty, mammoplasty |
| **-desis** | Binding, fusion | arthrodesis, spondylodesis |
| **-clasis** | Surgical breaking | osteoclasis |
| **-rrhaphy** | Suture | herniorrhaphy, neurorrhaphy |
| **-centesis** | Puncture for fluid removal | thoracentesis, paracentesis, amniocentesis, pericardiocentesis |
| **-lithotomy** | Cutting out a stone | nephrolithotomy |
| **-lithotripsy** | Crushing a stone | lithotripsy |

## Decoding practice

| Term | Decode |
|---|---|
| **Cholecystectomy** | cholecyst (gallbladder) + ectomy (removal) |
| **Nephrolithotomy** | nephro (kidney) + litho (stone) + tomy (cutting) = surgical removal of kidney stone |
| **Colonoscopy** | colono (colon) + scopy (look) |
| **Hyperglycemia** | hyper (high) + glyc (sugar) + emia (blood) |
| **Osteomalacia** | osteo (bone) + malacia (softening) |
| **Hematuria** | hemat (blood) + uria (urine) |
| **Bradycardia** | brady (slow) + cardia (heart) |
| **Splenomegaly** | spleno (spleen) + megaly (enlargement) |
| **Thrombocytopenia** | thrombo (clot) + cyto (cell) + penia (deficiency) |
| **Hemiplegia** | hemi (half) + plegia (paralysis) |

<HighYield variant="boards">
- **-ectomy** = remove. **-otomy** = cut into. **-ostomy** = create opening. (Common test of distinguishing.)
- **-itis** = inflammation. **-osis** = abnormal condition (not necessarily inflammation).
- **-emia** = blood. **-uria** = urine.
- **-pnea** = breathing. **Apnea** = none. **Tachypnea** = fast. **Bradypnea** = slow. **Dyspnea** = difficult.
- **-plegia** = paralysis. **-paresis** = weakness.
- **-cyte** = cell. **-blast** = immature/precursor cell. **-clast** = breaks down.
- **-phagia** = swallowing. **-phasia** = speech. (Distinguish dysphagia vs dysphasia.)
- **-rrhea** = flow/discharge. **-rrhage** = burst/bleed. **-rrhexis** = rupture. **-rrhaphy** = suture.
- **-cele** = hernia/swelling/cavity.
- **-pexy** = surgical fixation (e.g., orchidopexy = move undescended testis).
- **-tripsy** = crushing (lithotripsy = breaking stones).
- **-centesis** = puncture for fluid (thoracentesis, paracentesis).
</HighYield>
