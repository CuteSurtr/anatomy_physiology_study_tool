## Procedural suffixes recap

| Suffix | Procedure |
|---|---|
| **-ectomy** | Surgical removal |
| **-tomy** | Cutting/incision (does not remove) |
| **-stomy** | Creating a new opening |
| **-pexy** | Surgical fixation |
| **-plasty** | Surgical repair / reconstruction |
| **-desis** | Binding, fusion |
| **-clasis** | Surgical breaking |
| **-rrhaphy** | Suturing |
| **-centesis** | Puncture for fluid aspiration |
| **-scopy** | Visual exam via scope |
| **-graphy** | Radiographic imaging |
| **-gram** | The resulting image |

## Surgical approaches

| Term | Description |
|---|---|
| **Open surgery** | Traditional large incision |
| **Laparoscopic** | Several small abdominal ports + camera |
| **Robotic** | Surgeon at console controls robotic arms |
| **Endoscopic** | Through a body orifice with flexible scope (no skin incision) |
| **Percutaneous** | Through skin (small puncture) |
| **Transluminal** | Through a vessel lumen |
| **Transcatheter** | Via catheter |
| **MIS (minimally invasive)** | General umbrella term |
| **NOTES** | Natural orifice transluminal endoscopic surgery |
| **SILS / single-port** | Single incision laparoscopic |

## Anesthesia types

| Type | Description |
|---|---|
| **Local** | Lidocaine subQ; small procedure |
| **Regional** | Nerve block (femoral, brachial plexus) |
| **Spinal** | Subarachnoid injection |
| **Epidural** | Epidural space catheter (labor analgesia, post-op) |
| **MAC (monitored anesthesia care)** | "Conscious sedation" |
| **General anesthesia (GA)** | Unconscious, often intubated |
| **TIVA** | Total IV anesthesia (no inhaled agent) |

## ASA physical status (preop)

| Class | Description |
|---|---|
| **I** | Healthy |
| **II** | Mild systemic disease (controlled HTN, smoker) |
| **III** | Severe systemic disease (CAD, COPD, ESRD) |
| **IV** | Constant threat to life (recent MI, sepsis) |
| **V** | Moribund - not expected to survive without surgery |
| **VI** | Brain-dead organ donor |
| **E** | Emergency (added to any of above) |

## Suture types

| Type | Use |
|---|---|
| **Absorbable** (Vicryl, Monocryl, PDS, chromic gut, plain gut) | Internal, deep dermal, mucosal |
| **Non-absorbable** (Prolene, Nylon, silk, stainless steel) | Skin, vascular, tendon |
| **Monofilament** (Prolene, Monocryl, Nylon) | Less tissue reaction; vascular; smooth |
| **Multifilament / braided** (Silk, Vicryl) | Better handling; ligatures |
| **Sizes** | 0 (large) → 4-0 (small) → 10-0 (microsurgery) |

<HighYield variant="boards">
- **-ectomy** = remove; **-otomy** = incise (no removal); **-ostomy** = make opening.
- **CABG** for severe multivessel CAD + L main + reduced EF.
- **PCI** for STEMI within 90 min preferred.
- **Whipple** = head of pancreas + distal stomach + duodenum + gallbladder + bile duct.
- **APR** = abdominoperineal resection = removes rectum + anus → permanent colostomy.
- **TIPS** = portal HTN shunt; complication = hepatic encephalopathy.
- **VP shunt** = hydrocephalus (cerebral ventricle → peritoneum).
- **DBS** = subthalamic nucleus or globus pallidus; Parkinson + tremor.
- **LASIK** = laser-assisted in situ keratomileusis.
- **Mohs surgery** = skin cancer with margin checks (BCC, SCC).
- **POD#1-2** common DVT, fever (atelectasis, infection later).
- **Wound class I** (clean) vs IV (dirty/infected).
- **ASA II** = mild systemic disease; **ASA IV** = severe constant threat.
- **NPO after midnight** for AM surgery (clear liquids up to 2 h pre-op).
</HighYield>
