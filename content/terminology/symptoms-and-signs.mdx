## Symptom vs sign

| Term | Definition |
|---|---|
| **Symptom** | What the **patient reports** subjectively. "I feel dizzy." (history) |
| **Sign** | What the **examiner observes/measures** objectively. Heart murmur, jaundice. (physical exam, labs, imaging) |

Some findings are both (rash = patient sees it AND examiner sees it). The distinction matters most in writing up cases - symptoms in HPI/ROS, signs in PE.

## Disease descriptors

| Term | Meaning |
|---|---|
| **Acute** | Sudden onset; usually short duration |
| **Subacute** | Between acute + chronic (~weeks) |
| **Chronic** | Long duration / persistent |
| **Insidious** | Gradual onset (often missed) |
| **Fulminant** | Rapid + severe (often fatal) |
| **Indolent** | Slow-progressing (often cancer) |
| **Recurrent** | Returns after period of well-being |
| **Relapsing-remitting** | Episodes alternating with remission |
| **Progressive** | Worsening over time |
| **Stable** | Not changing |
| **Resolving** | Getting better |
| **Refractory** | Doesn't respond to treatment |
| **Idiopathic** | No known cause |
| **Iatrogenic** | Caused by medical treatment |
| **Nosocomial / healthcare-associated** | Acquired in hospital |
| **Cryptogenic** | Origin obscure |
| **Hereditary / familial / genetic** | Inherited |
| **Congenital** | Present at birth (may or may not be genetic) |
| **Acquired** | Develops after birth |
| **Primary** | Initial disease |
| **Secondary** | Caused by another condition |
| **Tertiary** | Late manifestation |
| **Localized** | Confined to one area |
| **Generalized / diffuse / systemic** | Widespread |
| **Focal** | Limited to one area |
| **Disseminated** | Spread |
| **Metastatic** | Spread (usually cancer) |
| **Benign** | Non-cancerous |

## Pain descriptors

| Term | Meaning |
|---|---|
| **Sharp** | Sudden, well-localized |
| **Dull** | Aching, diffuse |
| **Burning** | Like fire (often neuropathic) |
| **Stabbing** | Like a knife |
| **Pressure** | Heavy, vise-like |
| **Crushing** | Severe pressure (classic for MI) |
| **Squeezing** | Like a band |
| **Throbbing** | Pulsing |
| **Colicky** | Crampy, wave-like (intestinal, ureteric) |
| **Boring** | Drilling deep (pancreatitis) |
| **Lancinating** | Shooting (neuropathic) |
| **Tingling, paresthesia** | "Pins and needles" |
| **Numbness, hypoesthesia** | Reduced sensation |
| **Allodynia** | Pain from non-painful stimulus (light touch) |
| **Hyperalgesia** | Increased pain from painful stimulus |
| **Referred pain** | Felt at site distant from origin (e.g., MI → arm/jaw) |
| **Radicular** | Following a nerve root (sciatica) |
| **Pleuritic** | Worse with breathing |

## OPQRST (history of pain)

- **O**nset.
- **P**rovocation / palliation (what makes worse/better).
- **Q**uality (sharp, dull, etc.).
- **R**adiation.
- **S**everity (1-10 scale).
- **T**iming (constant, episodic).

## Common confusables in clinical writing

| Pair | Difference |
|---|---|
| Hypertension vs hypotension | High vs low BP |
| Hyperglycemia vs hypoglycemia | High vs low glucose |
| Tachycardia vs bradycardia | Fast vs slow heart |
| Hyper- vs hypo- (everything) | Above vs below normal |
| Hematemesis vs hemoptysis | Vomiting blood vs coughing blood |
| Hematuria vs hemoptysis | Blood in urine vs blood from lungs |
| Melena vs hematochezia | Black tarry (upper) vs bright red (lower) GI bleed |
| Dysphagia vs dysphasia | Swallowing vs speech |
| Aphasia vs dysarthria | Language disorder vs slurred articulation |
| Anesthesia vs analgesia | No sensation vs no pain |
| Paresis vs paralysis (plegia) | Weakness vs total loss |

<HighYield variant="boards">
- **Symptoms** = patient-reported. **Signs** = objectively detected.
- "**Acute**" = sudden; "**chronic**" = long-standing.
- "**Idiopathic**" = unknown cause; "**iatrogenic**" = caused by treatment.
- **OPQRST** for pain history.
- **Crushing substernal pain radiating to L arm + jaw** = MI.
- **Pleuritic pain** = worse with breathing; PE, pneumonia, pericarditis.
- **Murphy's sign** + RUQ pain = cholecystitis.
- **Cullen's sign** (periumbilical bruising) + **Grey Turner's** (flank) = hemorrhagic pancreatitis.
- **Hemoptysis** = lungs; **hematemesis** = stomach; **hematochezia** = lower GI; **melena** = upper GI.
- **Dysphagia** vs **dysphasia** vs **dysarthria** - swallowing vs language vs slurred articulation.
- **Pulsus paradoxus** = ↓ SBP >10 mmHg with inspiration → cardiac tamponade.
- **Cheyne-Stokes** = crescendo-decrescendo with apnea (HF, brain injury).
- **Kussmaul** = deep + labored (DKA).
</HighYield>
