## "Do Not Use" list (Joint Commission)

Use the **written-out** form on official orders. These abbreviations cause errors:

| Avoid | Use |
|---|---|
| **U, IU** (mistaken for 0, 4) | "unit" |
| **Q.D., QD** (mistaken for QID) | "daily" |
| **Q.O.D., QOD** | "every other day" |
| **Trailing zero (X.0 mg)** | "X mg" (no trailing 0) |
| **Lacking leading zero (.X mg)** | "0.X mg" (always leading 0) |
| **MS** | "morphine sulfate" or "magnesium sulfate" |
| **MSO₄, MgSO₄** | Same - spell out |
| **AS / AD / AU** | "left ear / right ear / both ears" |
| **OS / OD / OU** | "left eye / right eye / both eyes" |
| **D/C** | "discharge" or "discontinue" - spell out |
| **cc** | "mL" (cc can be mistaken for "U") |
| **µg, mcg confused** | "microgram" or always "mcg" |
| **HS** | "half strength" or "at bedtime" - spell out |
| **TIW** | "3 times weekly" - spell out |
| **SC, SQ, sub q** | "subcut" or "subcutaneously" |
| **per os** (po) | "by mouth" (po OK on many systems) |
| **&lt;, &gt;** | "less than" / "greater than" (can be confused with each other or letters) |

## Common error patterns to recognize

- **"u" or "U"** → 0 misread → 10-fold overdose ("10 U" → "100"). Write "10 units."
- **".5"** → "5" missed → 10-fold overdose. Write "0.5".
- **"5.0"** → "50" misread → 10-fold overdose. Write "5" (no trailing zero).
- **"QD"** → "QID" misread → 4-fold overdose. Write "daily."
- **"MS"** → ambiguous (morphine vs magnesium). Write the full name.

<HighYield variant="boards">
- **NPO** = nothing by mouth.
- **PRN** = as needed.
- **PO** = by mouth.
- **STAT** = immediately.
- **QID** = 4×/day; **TID** = 3×/day; **BID** = 2×/day; **QHS** = at bedtime.
- **QOD** = avoid (use "every other day").
- **HFrEF** ≤40%; **HFpEF** ≥50%; **HFmrEF** 41-49%.
- **STEMI** = ST-elevation MI; **NSTEMI** = no ST elevation.
- **DKA** vs **HHS**: DKA has anion-gap acidosis + ketones; HHS has very high glucose + osmolality without significant ketosis.
- **DNR** = do not resuscitate (no CPR). **DNI** = do not intubate. These are distinct.
- "**MS**" alone → ambiguous (morphine sulfate vs magnesium sulfate vs multiple sclerosis). Always specify.
