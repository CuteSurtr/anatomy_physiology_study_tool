Medical terminology looks intimidating but follows simple rules. Every medical term is a combination of **prefix + word root(s) + suffix** with **combining vowels** glued in to keep pronunciation smooth.

## The four building blocks

| Element | What it does | Example |
|---|---|---|
| **Root** | The core meaning - usually an organ or tissue | **gastr** = stomach |
| **Prefix** | Modifier at the start - location, time, number, color | **epi**- = above |
| **Suffix** | Modifier at the end - condition, procedure, specialty | -**itis** = inflammation |
| **Combining vowel** | "Glue" (usually **o**) between root and another root/suffix that begins with consonant | gastr-**o**-enter-itis |

## Decoding example - "gastroenterology"

Break it down:
- **gastr** (root) = stomach
- **o** (combining vowel)
- **enter** (root) = intestine
- **o** (combining vowel)
- **-logy** (suffix) = study of

= **"study of stomach + intestines"** = the medical specialty.

## Combining vowel rule

Use a combining vowel when:
- Connecting **two roots** → almost always: gastr**o**enter, cardi**o**megaly, hyster**o**salping**o**gram.
- Connecting a root to a suffix that **begins with a consonant** → use vowel: cardi**o**logy (not "cardlogy").

Don't use a combining vowel when:
- The suffix **starts with a vowel** → drop it: cardi**itis** is wrong, but **gastritis** is correct (not "gastr-o-itis"). The "o" is dropped because **-itis** starts with a vowel.

## Building vs decoding

| Direction | How |
|---|---|
| **Decode** (read a term) | Start at the **end** (suffix), then the beginning (prefix), then the middle (root) |
| **Build** (construct a term) | Choose the root → add prefix for modifier → add suffix for what's happening |

**Decode "hysterosalpingectomy"**:
- **-ectomy** = surgical removal
- **hyster/o** = uterus
- **salping/o** = uterine tube (fallopian)
- → "surgical removal of the uterus + fallopian tubes."

## Plural rules from Latin/Greek

Most medical plurals come from Latin and Greek, not English "+s." A few patterns:

| Singular → Plural | Example |
|---|---|
| -a → -ae | vertebra → vertebrae, pleura → pleurae |
| -us → -i | nucleus → nuclei, bronchus → bronchi, alveolus → alveoli |
| -um → -a | datum → data, atrium → atria, ovum → ova |
| -is → -es | diagnosis → diagnoses, metastasis → metastases, testis → testes |
| -ex/-ix → -ices | apex → apices, appendix → appendices |
| -ma → -mata | carcinoma → carcinomata (also carcinomas), stoma → stomata |
| -on → -a | ganglion → ganglia, phenomenon → phenomena, criterion → criteria |
| -nx → -nges | phalanx → phalanges, larynx → larynges |
| -en → -ina | foramen → foramina, lumen → lumina |

## Combining forms to memorize

A **combining form** is the root + its combining vowel: `gastr/o`, `cardi/o`, `nephr/o`. You'll see these listed in references.

## Why this matters clinically

Once you know that:
- **hepat/o** = liver
- **-megaly** = enlargement
- **-itis** = inflammation
- **-osis** = abnormal condition

You can immediately read **"hepatomegaly"**, **"hepatitis"**, **"hepatosis"** without ever having seen those exact words. This is the multiplier effect of word parts.

## Pronunciation tips

- Latin-derived: classical (eponyms, anatomy): **vena cava** = VEE-nuh KAH-vuh.
- Greek-derived: medical specialties, conditions: **pneumonia** = noo-MOH-nee-uh (silent p).
- "ch" before -e or -i is often "k" (Greek): **chronic** = KRON-ik.

## Common patterns to recognize

| Pattern | Meaning | Example |
|---|---|---|
| **-itis** | Inflammation | appendicitis, otitis, dermatitis |
| **-osis** | Abnormal condition | cyanosis, halitosis, nephrosis |
| **-ectomy** | Surgical removal | appendectomy, mastectomy |
| **-tomy** | Cutting/incision | tracheotomy, laparotomy |
| **-stomy** | Creating an opening | colostomy, tracheostomy |
| **-graphy** | Process of recording | mammography, angiography |
| **-gram** | The record/image | electrocardiogram (ECG), mammogram |
| **-scopy** | Looking with a scope | endoscopy, colonoscopy |
| **-plasty** | Surgical repair | rhinoplasty, angioplasty |
| **-pathy** | Disease | neuropathy, retinopathy |
| **-algia** | Pain | neuralgia, myalgia |
| **-dynia** | Pain (less common) | mastodynia |

## Negatives + privatives

| Prefix | Meaning | Example |
|---|---|---|
| **a-, an-** | Without | apnea, asystole, anemia |
| **anti-** | Against | antihypertensive, antibiotic |
| **contra-** | Against | contraindication |
| **dys-** | Bad, painful, difficult | dyspnea, dysphagia, dysuria |
| **mal-** | Bad | malabsorption, malignant |
| **mis-** | Wrong | misdiagnosis |

## Eponyms - "named for"

Some terms are named after people (anatomist, physician, patient): **Parkinson** disease, **Crohn** disease, **Lou Gehrig** disease. Newer style guides prefer non-possessive forms (Parkinson disease, not Parkinson's). Many countries and journals differ on this.

## Common pitfall - homophones

Distinguishable only by spelling + context:

| Pair | Difference |
|---|---|
| **Ileum** vs **Ilium** | Ileum (E) = last small intestine. Ilium (I) = bone of pelvis. "Eat with the E - intestine." |
| **Mucus** (noun) vs **Mucous** (adj) | Mucus = the substance. Mucous = describing membrane. "Mucous membrane secretes mucus." |
| **Dysphagia** vs **Dysphasia** | -**ph**agia = swallowing. -**ph**asia = speech. |
| **Perineum** vs **Peritoneum** | Perineum = area between anus + genitals. Peritoneum = abdominal serous membrane. |
| **Palpate** vs **Palpitate** | Palpate = examine by touch. Palpitate = abnormal heartbeat sensation. |
| **Hypo-** vs **Hyper-** | Hypo = under/low. Hyper = over/high. |

## When to consult a reference

If you encounter:
- An unfamiliar term in a chart: **decode it**.
- A term that doesn't match expected anatomy: **double-check spelling**.
- A drug or eponym: **look it up** (eponyms don't decode).

Medical dictionaries (Stedman's, Dorland's) and online resources (Merriam-Webster Medical, drugs.com for medications) are essential references.

- Decode terms from the **end backwards** (suffix → prefix → root).
- Combining vowel is dropped before a vowel-starting suffix: gastr**itis** not gastr**o**itis.
- "**Ileum**" = intestine; "**ilium**" = hip bone. The bone is "ili-" like the "iliac."

- Plural of -us → -i: bronchus → bronchi, alveolus → alveoli, nucleus → nuclei.
- Plural of -is → -es: diagnosis → diagnoses, metastasis → metastases.
- Plural of -ma → -mata or -mas: carcinoma → carcinomata/carcinomas.
- Plural of -nx → -nges: phalanx → phalanges, meninx → meninges.
