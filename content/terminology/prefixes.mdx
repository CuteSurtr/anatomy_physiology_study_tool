Prefixes modify the meaning of a root, usually by indicating **where, when, how much, or what kind**. Many come in opposite pairs.

## Position + direction

| Prefix | Meaning | Examples |
|---|---|---|
| **ab-** | Away from | abduction, abnormal |
| **ad-** | Toward, near | adduction, adrenal (on top of), adhesion |
| **ante-** | Before, in front of | antepartum, anterior |
| **post-** | After, behind | postpartum, posterior, postprandial |
| **circum-, peri-** | Around | circumcision, pericardium, periosteum |
| **dia-** | Through, across, complete | diagnosis, diabetes, diarrhea |
| **trans-** | Across, through | transplant, transudate, transverse |
| **ec-, ex-, ecto-, exo-** | Out of, outside | ectopic, excise, exocrine |
| **endo-, ento-, intra-, intro-** | Within | endoscope, intracellular, introduce |
| **inter-** | Between | intercostal, intervertebral |
| **epi-** | Upon, above | epidermis, epigastric, epiglottis |
| **hypo-, sub-, infra-** | Beneath, below | hypoglossal, subcutaneous, infraorbital |
| **hyper-, super-, supra-** | Above, beyond | hypertension, supraclavicular, superficial |
| **meso-** | Middle | mesoderm, mesentery |
| **medi-, mid-** | Middle | medial, midsagittal |
| **lat-, latero-** | Side | lateral, ipsilateral, contralateral |
| **dextro-** | Right | dextrocardia |
| **sinistro-, levo-** | Left | levocardia, sinistral |
| **retro-** | Behind, backward | retroperitoneal, retrograde |
| **pro-** | Before, forward | prognosis, prodrome |
| **infra-** | Below | infrasternal, infraorbital |
| **ultra-** | Beyond | ultrasound |

## Common confusable prefixes

- **inter-** (between) vs **intra-** (within): "**inter**costal" (between ribs) vs "**intra**venous" (within vein).
- **per-** (through) vs **peri-** (around): "**per**cutaneous" (through skin) vs "**peri**cardium" (around heart).
- **ante-** (before) vs **anti-** (against): "**ante**partum" (before birth) vs "**anti**body" (against pathogen).
- **dys-** (bad) vs **dis-** (apart, away): "**dys**function" vs "**dis**section."

## Quick test - decode

| Term | Decode |
|---|---|
| **Hyperglycemia** | hyper (excessive) + glyc (sugar) + emia (blood) = high blood sugar |
| **Polyuria** | poly (many) + uria (urine) = excessive urination |
| **Dyspnea** | dys (difficult) + pnea (breathing) = difficulty breathing |
| **Tachycardia** | tachy (fast) + cardia (heart) = fast heart rate |
| **Anemia** | an (without) + emia (blood) = literally "no blood" → low RBCs/hemoglobin |
| **Epidural** | epi (above) + dural (dura) = above the dura |
| **Subcutaneous** | sub (below) + cutaneous (skin) = below the skin |
| **Bilateral** | bi (two) + lateral (side) = both sides |

<HighYield variant="boards">
- **Hyper-** vs **hypo-**: hyper = above, hypo = below.
- **Tachy-** vs **brady-**: fast vs slow.
- **Poly-** vs **olig(o)-**: many vs few.
- **Pre-** vs **post-**: before vs after.
- **Ante-** vs **anti-**: before (time) vs against (opposition).
- **Endo/intra-** vs **exo/ecto-**: within vs outside.
- **Macro/mega-** vs **micro-**: large vs small.
- **Sub/infra/hypo-** vs **supra/super/epi-**: below vs above.
- "Pseudo-" = false. "Pseudohyperkalemia" = artifactually high K from hemolyzed sample.
</HighYield>
