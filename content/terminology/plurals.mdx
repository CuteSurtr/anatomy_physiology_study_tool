Medical English borrows from Latin and Greek, which means **English-style "+s" plurals don't work** for most terms. Patterns:

## Latin-derived plurals

### -us → -i
The most common pattern. The "-us" usually ends a Latin masculine word.

| Singular | Plural |
|---|---|
| nucleus | nuclei |
| bronchus | bronchi |
| alveolus | alveoli |
| bacillus | bacilli |
| villus | villi |
| musculus | musculi |
| **uterus** | uteri (rarely used; "uteruses" more common) |
| **virus** | viruses (NOT viri - "virus" was Latin neuter, not masculine) |

**Sinus** is unusual - both "sinuses" + "sinus" accepted.

### -a → -ae
Latin feminine.

| Singular | Plural |
|---|---|
| vertebra | vertebrae |
| pleura | pleurae |
| aorta | aortae (or "aortas") |
| bursa | bursae |
| conjunctiva | conjunctivae |
| fascia | fasciae |
| trachea | tracheae (uncommon; "tracheas") |
| **patella** | patellae |

### -um → -a

| Singular | Plural |
|---|---|

| ovum | ova |

| serum | sera (or "serums") |
| acetabulum | acetabula |
| diverticulum | diverticula |
| ileum | ilea |
| diaphragm | diaphragmata (or "diaphragms") |
| labium | labia |
| ligamentum | ligamenta |
| cilium | cilia |
| flagellum | flagella |
| antrum | antra |
| pudendum | pudenda |

For "-osis" + "-iasis" + "-itis" forms.

| Singular | Plural |

Latin third-declension.

| Singular | Plural |
|---|---|

| index | indices (or indexes) |

| Singular | Plural |
|---|---|

|---|---|

## Greek-derived plurals

### -ma → -mata
Many cancer/growth terms.

| Singular | Plural |
|---|---|
| carcinoma | carcinomata (or "carcinomas") |
| sarcoma | sarcomata (or "sarcomas") |
| lipoma | lipomata (or "lipomas") |
| myoma | myomata (or "myomas") |
| stoma | stomata |
| schema | schemata |
| stigma | stigmata |
| trauma | traumata (or "traumas") |

**Modern usage**: -mas is acceptable for many of these in clinical English. -mata is more formal/scientific.

### -nx → -nges

| Singular | Plural |
|---|---|
| phalanx | phalanges |
| larynx | larynges (rare; "larynxes" common) |
| pharynx | pharynges (rare; "pharynxes" common) |
| meninx | meninges |
| salpinx | salpinges |
| coccyx | coccyges (or "coccyxes") |

### -on → -a

| Singular | Plural |
|---|---|
| ganglion | ganglia |
| phenomenon | phenomena |
| criterion | criteria |
| protozoon | protozoa |
| spermatozoon | spermatozoa |
| mitochondrion | mitochondria |

### -is → -ides (some Greek)

| Singular | Plural |
|---|---|
| iris | irides (or "irises") |
| ascaris | ascarides |
| chondrocyte | chondrocytes (regular English) |

### -os, -on → -a, -i (variable)

| Singular | Plural |
|---|---|
| bronchus (Gr. -os) | bronchi |
| metacarpus | metacarpi |

## Anglicized plurals - when acceptable

Modern American medical English increasingly uses "-s" plurals where the form is well-established:

- **viruses** (always - "viri" never accepted).
- **muscles** (always).
- **uteruses** (informal; "uteri" formal).
- **carcinomas** (acceptable; "carcinomata" formal/journal).
- **sarcomas** (acceptable).
- **diaphragms** (acceptable).
- **traumas** (acceptable for journalism + casual).
- **fistulas** (acceptable; "fistulae" formal).
- **larynxes / pharynxes** (acceptable spoken; "larynges/pharynges" formal).

When in doubt for formal writing → use the classical form. Casual + spoken → either.

## Pronunciation tips

- **-ae** = "ee" (vertebrae → ver-TEH-bray or ver-TEH-bray; varies).
- **-i** (plural of -us) = "ee" or "eye" - both heard.
- **-ces** (plural of -ex/-ix) = "sees" (apices → AY-peh-seez).
- **-mata** = "muh-tuh" or "mat-uh" (carcinomata → kar-sih-NO-muh-tuh).

## Common confusion

- **Bacteria** is PLURAL (singular = bacterium). "Bacteria is" is grammatically incorrect; "bacteria are" is right. (Though even physicians slip on this.)
- **Data** is PLURAL (singular = datum). "Data are" - though "data is" has become accepted in modern usage.
- **Criteria** is PLURAL (singular = criterion). "The criterion is" / "The criteria are."
- **Phenomena** is PLURAL (singular = phenomenon).

<HighYield variant="boards">
- "Bacterium" is singular; **"bacteria"** is plural ("the bacteria are").
- "Datum" is singular; **"data"** is plural ("the data are").
- "Criterion" is singular; **"criteria"** is plural.
- **Diagnoses** (multiple): "the patient has two diagnoses."
- **Metastases** (more than one): "evaluate for metastases."
- **Phalanges** (more than one finger bone).
- **Foramina** (more than one foramen) - holes in skull, vessels enter/exit.
- **Lumina** (more than one lumen) - tubes (vessels, intestine).
- **Apices** (more than one apex) - apex of lung, heart, root of tooth.
- **Stoma** singular; **stomata** plural (formal) or "stomas" (casual).
- **Trauma** singular; "traumas" common modern usage.
- **Viruses** is the plural (NOT "viri" - virus was Latin neuter, never had a plural in Latin).
