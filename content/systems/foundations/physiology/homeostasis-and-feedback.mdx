Homeostasis is the maintenance of a relatively stable **internal environment** despite external change. It's not a single mechanism but a collection of feedback loops that defend hundreds of regulated variables - body temperature, blood pressure, plasma osmolality, pH, glucose, oxygen, calcium, sodium, and dozens more.

Claude Bernard called it the *milieu intérieur* in 1865. Walter Cannon coined "homeostasis" in 1932. Almost every disease can be reframed as failed homeostasis.

## The components of any control system

Every feedback loop has the same five parts:

| Component | Job | Example (thermoregulation) |
|---|---|---|
| **Stimulus** | The disturbance | Cold environment |
| **Sensor / receptor** | Detects change | Skin cold receptors, hypothalamic thermoreceptors |
| **Control center** | Integrates input, compares to set point | Hypothalamus (preoptic area) |
| **Effector** | Carries out the response | Skeletal muscle (shivering), skin vessels (vasoconstriction), TSH/thyroid (heat generation) |
| **Response** | The corrective action | Core temperature rises back to ~37°C |

The **set point** is the value the system defends. The **error signal** is the difference between current value and set point. Effectors are activated proportionally to error.

## Negative feedback - the default

<Figure name="foundations/negative-feedback-loops" caption="Negative feedback loops - sensor detects deviation from a set point → control center compares → effector produces opposing response. The default homeostatic mechanism for nearly every regulated variable (OpenStax)." />

The output of the loop **opposes** the original change. Stable, self-correcting, gives oscillation around a set point. This is how the body regulates nearly everything.

**Examples (memorize this list):**
- **Blood glucose** ↑ → β cells release insulin → glucose ↓
- **Blood glucose** ↓ → α cells release glucagon → glucose ↑
- **Core temperature** ↑ → sweating + cutaneous vasodilation → temperature ↓
- **Core temperature** ↓ → shivering + cutaneous vasoconstriction → temperature ↑
- **Blood pressure** ↑ → baroreceptors → ↓ sympathetic tone → BP ↓
- **Plasma osmolality** ↑ → osmoreceptors → ADH release → water retention → osmolality ↓
- **Blood Ca²⁺** ↓ → PTH from parathyroid → ↑ bone resorption + renal Ca²⁺ reabsorption + ↑ calcitriol → Ca²⁺ ↑
- **Blood O₂** ↓ → peripheral chemoreceptors → ↑ ventilation → O₂ ↑
- **Blood CO₂** ↑ → central chemoreceptors → ↑ ventilation → CO₂ ↓
- **Thyroid hormone (T₃/T₄)** ↑ → suppresses TRH + TSH → T₃/T₄ ↓
- **Cortisol** ↑ → suppresses CRH + ACTH → cortisol ↓

Notice the pattern: most endocrine axes operate as **long-loop negative feedback** from the target hormone back to the hypothalamus and pituitary.

## Positive feedback - the rare exception

Output **amplifies** the original change. Explosive, self-terminating only when the trigger is removed or the process is complete. The body uses it sparingly - only when a quick, all-or-nothing event is needed.

<Figure name="foundations/positive-feedback-pregnancy" caption="Positive feedback in childbirth - cervical stretch stimulates oxytocin release from the posterior pituitary, which intensifies uterine contractions, which further stretch the cervix. The loop only terminates when the baby is delivered." />

**Examples (only a handful):**

| Process | Trigger | Amplification | Termination |
|---|---|---|---|
| **Childbirth** | Cervical stretch | Oxytocin → uterine contractions → more stretch | Delivery |
| **Blood clotting** | Vessel injury → thrombin generation | Thrombin activates V, VIII, XI → more thrombin | Antithrombin III, protein C, plasmin |
| **Action potential** | Threshold depolarization | Na⁺ influx → more depolarization → more Na⁺ channels open | Na⁺ channel inactivation, K⁺ efflux |
| **LH surge** at ovulation | Sustained high estrogen | Estrogen switches from − to + feedback on pituitary → LH spike → ovulation | Follicle ruptures; estrogen falls |
| **Lactation milk-ejection reflex** | Suckling | Oxytocin → milk ejection → more suckling | Infant disengages |

<Note title="Why positive feedback is dangerous">
A positive feedback loop with no built-in shutoff is a death spiral. **Cardiogenic shock** is a clinical example: low cardiac output → low coronary perfusion → ischemic myocardium → lower cardiac output. Without intervention, the patient dies.

The body's positive feedback loops always have a hard stop built in - delivery, vessel sealing, channel inactivation, follicle rupture, end of feeding.
</Note>

## Feedforward control - anticipation

The body doesn't only react. **Feedforward** anticipates a disturbance based on a leading signal. Examples:
- **Cephalic phase of digestion**: the sight, smell, or thought of food triggers gastric acid and salivary secretion *before* food arrives
- **Postural blood pressure regulation**: vestibular input adjusts sympathetic tone before standing
- **Exercise hyperpnea**: ventilation rises within seconds of starting exercise, before any measured change in CO₂

Feedforward is open-loop (no error signal) and works in parallel with feedback.

## Set-point adjustment (allostasis)

Set points are not fixed. They can be shifted by:
- **Circadian rhythm** - cortisol peaks at dawn; body temperature lowest at 4 a.m.
- **Fever** - cytokines (IL-1, IL-6, TNF, prostaglandin E₂) raise hypothalamic temperature set point; the body shivers to reach the new (febrile) set point. Antipyretics (acetaminophen) inhibit COX-2 in the hypothalamus and reset the thermostat.
- **Acclimatization** - chronic altitude → erythropoietin ↑ → higher hematocrit; chronic heat → sweat composition becomes less salty.
- **Pregnancy** - many set points shift: plasma volume ↑, MAP ↓ slightly, respiratory rate ↑, threshold for thirst lowers.

**Allostasis** = achieving stability through change. The "set point" view is an oversimplification; the body actively anticipates demand and pre-adjusts.

## Disease as broken homeostasis

| Failure mode | Example |
|---|---|
| Sensor fails | Diabetes insipidus (no ADH-producing neurons), congenital insensitivity to pain |
| Control center fails | Stroke damaging hypothalamic thermoregulatory center → poikilothermia |
| Effector fails | Heart failure - cannot raise CO despite normal sympathetic drive |
| Set point shifted | Hypertension - baroreceptors reset to higher BP; fever; obesity body-weight set point |
| Loop gain too high | Cushing's reflex; reflex tachycardia from antihypertensives |
| Loop gain too low | Orthostatic hypotension - sluggish baroreflex |
| Positive feedback with no shutoff | Cardiogenic shock, septic shock, hemorrhagic shock |

<HighYield exam="step1">
**Classic exam framings:**
- Identify which loop has failed in a vignette - sensor / center / effector / set point?
- Positive vs negative feedback - **clotting, parturition, LH surge, action potential** are the *only* common positive feedback examples.
- A drug that lowers thyroid hormone will cause **TSH to rise** because long-loop negative feedback is intact.
- Fever isn't broken thermoregulation - it's thermoregulation defending a higher set point. **Don't reflexively cool a febrile patient** with ice baths (causes shivering and discomfort); use antipyretics to lower the set point.
- Type 1 diabetes = failed effector (β cell loss). Type 2 = failed receptor sensitivity (insulin resistance). Both result in chronic hyperglycemia but the homeostatic break is different.
</HighYield>

<HighYield exam="nclex">
**Bedside applications:**
- Measure vitals as a window onto homeostasis: HR, BP, RR, SpO₂, temp.
- **MAP < 65 mmHg** → organ perfusion at risk.
- **SpO₂ < 90%** → tissue oxygenation threshold for supplemental O₂.
- **Temperature > 38.3°C or < 36°C** → sepsis criterion.
- A patient whose vitals stop fluctuating is not "stable" - they may have lost autonomic regulation (e.g. brainstem injury, terminal patient).
</HighYield>
