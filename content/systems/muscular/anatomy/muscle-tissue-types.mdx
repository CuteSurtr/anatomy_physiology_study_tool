The body has three muscle tissue types - **skeletal, cardiac, smooth** - that look alike under a casual glance but differ profoundly in **structure, regulation, contraction speed, and disease patterns**. They share the same basic actin-myosin sliding-filament mechanism but couple it to different Ca²⁺ sources, different membrane systems, and very different controls.

<Figure name="muscular/muscle-tissue" caption="The three muscle tissue types under light microscopy. Skeletal: long, multinucleated, striated. Cardiac: branched, central nucleus, intercalated discs. Smooth: spindle-shaped, no striations." />

<Figure name="muscular/sarcomere" caption="Sarcomere - the functional unit of striated (skeletal + cardiac) muscle." />

## At-a-glance comparison

| Feature | Skeletal | Cardiac | Smooth |
|---|---|---|---|
| **Striations** | Yes (clear sarcomeres) | Yes | **No** (no organized sarcomeres) |
| **Nuclei per cell** | Many (peripheral) | 1–2 (central) | 1 (central) |
| **Cell shape** | Long cylindrical fibers (many cm) | Branched, short (~100 μm) | Fusiform/spindle (~100 μm) |
| **Intercalated discs** | None | **Yes** - gap junctions + desmosomes; functional syncytium | None |
| **Control** | Voluntary (somatic motor) | Autonomic + intrinsic pacemaker | Autonomic + hormonal + stretch |
| **Source of Ca²⁺** | **SR only** (via DHPR–RyR1 mechanical coupling) | SR + extracellular ("Ca-induced Ca release" via DHPR–RyR2) | SR (IP3R) + extracellular (L-type) |
| **Length-tension** | Sliding filament; tetanus possible | Sliding filament; no tetanus (long absolute refractory) | "Latch state" + plastic |
| **Regulation** | **Troponin C** (Ca²⁺ binds → moves tropomyosin) | Same as skeletal | **Calmodulin → MLCK → MLC phosphorylation** (Ca²⁺ binds calmodulin, not troponin) |
| **Fuel** | Glycogen + creatine phosphate + fatty acids | Predominantly fatty acids (60–70%); aerobic | Glucose + fatty acids; aerobic |
| **Regeneration** | Limited - **satellite cells** can fuse to add nuclei | Almost none → scar formation post-MI | Yes - can proliferate (uterus in pregnancy) |
| **Hypertrophy** | Sarcomere addition with training | Concentric (pressure) or eccentric (volume) | Hyperplasia + hypertrophy |

## Skeletal muscle - voluntary, striated

### Structural hierarchy
```
Muscle → Fascicle (epimysium → perimysium) → Fiber (cell, sarcolemma) → Myofibril → Sarcomere
```

| Connective tissue layer | Wraps |
|---|---|
| **Epimysium** | Entire muscle |
| **Perimysium** | Fascicles (bundles of fibers) |
| **Endomysium** | Each individual muscle fiber |

### The sarcomere - functional unit
- **Z line** to **Z line** = one sarcomere (~2 μm at rest).
- **A band** = full length of thick filaments (myosin); doesn't change length.
- **I band** = thin filaments only; shortens during contraction.
- **H zone** = thick only (middle of A band); shortens.
- **M line** = middle of H zone - myomesin proteins anchor myosin.

<Mnemonic>
**"A band = Always; I band = It shrinks; H zone = Hugely shrinks; Z line = Z lines come together"** - only the A band stays constant during contraction.
</Mnemonic>

### Fiber types
| Type | Other names | Speed | Fatigue | Mitochondria | Myoglobin | Best for |
|---|---|---|---|---|---|---|
| **Type I (slow oxidative)** | Slow twitch, red | Slow | Resistant | Many | Lots (red) | Endurance (postural muscles, marathon) |
| **Type IIa (fast oxidative)** | Intermediate | Fast | Moderate | Many | Lots (red) | Moderate-duration moderate-power |
| **Type IIx/b (fast glycolytic)** | Fast twitch, white | Fast | Quick | Few | Little (white) | Sprint, power, weight lifting |

Aging → preferential loss of type II → sarcopenia (loss of fast fibers, strength).

### Neuromuscular junction (NMJ) - control point
- **ACh** released from motor axon → binds **nicotinic AChR** (Nm subtype) on motor end plate → opens cation channel → end-plate potential → if threshold reached → AP propagates → T-tubule depolarization → **DHPR** in T-tubule mechanically couples to **RyR1** in SR → Ca²⁺ released → contraction.
- **AChE** in synaptic cleft terminates signal.

### NMJ pharmacology - every drug class
| Class | Examples | Mechanism |
|---|---|---|
| **AChE inhibitors** | Neostigmine, pyridostigmine, edrophonium | ↑ ACh in cleft (myasthenia, NMJ block reversal) |
| **Non-depolarizing NMJ blockers** | Rocuronium, vecuronium, atracurium ("-curium/-curonium") | Competitive Nm antagonists |
| **Depolarizing NMJ blocker** | Succinylcholine | Persistent depolarization → phase I block then phase II |
| **Botulinum toxin** | Botox | Blocks ACh **release** (cleaves SNARE proteins) |
| **Tetanus toxin** | - | Blocks inhibitory neurotransmitter release in spinal cord (GABA, glycine) → tonic muscle contraction (lockjaw) |
| **Anti-AChR antibodies** | Myasthenia gravis | Block + degrade receptors → fluctuating weakness |
| **Anti-VGCC antibodies** | Lambert-Eaton | Block presynaptic Ca²⁺ channels → ↓ ACh release; classic with small cell lung CA |

<Clinical>
**Malignant hyperthermia** - autosomal dominant RyR1 mutation. Triggered by inhaled halogenated anesthetics + succinylcholine → unregulated SR Ca²⁺ release → sustained contraction + hypermetabolism + hyperthermia (>40°C). Treat with **dantrolene** (blocks RyR1). Genetic testing for at-risk families.

**Myasthenia gravis** vs **Lambert-Eaton**: MG worsens with use (anti-AChR), spares autonomics, responds to AChE inhibitors. LEMS *improves* with use (anti-VGCC, autonomic involvement common, paraneoplastic SCLC), poor response to AChE alone.
</Clinical>

## Cardiac muscle - involuntary, striated, syncytial

### Distinguishing features
- **Branched** + shorter cells than skeletal; single (sometimes binucleate) central nucleus.
- **Intercalated discs** at cell-cell junctions:
  - **Desmosomes + fascia adherens** - mechanical coupling
  - **Gap junctions** (connexin 43) - electrical coupling → **functional syncytium**
- Striated like skeletal (same sarcomeric architecture) but with shorter T-tubules + smaller SR.
- **Long absolute refractory period** (~250 ms) - covers the entire contraction → can't tetanize.

### Excitation-contraction coupling - calcium-induced calcium release (CICR)
1. Depolarization → opens L-type Ca²⁺ channels in T-tubule.
2. Small Ca²⁺ influx triggers RyR2 in SR to release a larger Ca²⁺ store ("CICR").
3. Ca²⁺ binds troponin C → sliding filament contraction.
4. SERCA pumps Ca²⁺ back into SR; Na/Ca exchanger removes Ca²⁺ across sarcolemma.

This differs from skeletal muscle in two ways:
- Cardiac requires **extracellular Ca²⁺** entry (DHPR doesn't mechanically open RyR2 - it sends Ca²⁺ to open it).
- Skeletal can contract without extracellular Ca²⁺ - cardiac cannot.

### Cardiac muscle adaptations
- **High mitochondrial density** (30–40% cell volume).
- **Predominantly aerobic** - uses fatty acid β-oxidation, lactate, glucose, ketones.
- **Cardiac troponins (cTnI, cTnT)** released into blood when myocytes die - biomarkers of MI.
- **Almost no regenerative capacity** - necrotic tissue replaced by collagen scar.

## Smooth muscle - involuntary, non-striated

<Figure name="muscular/smooth-muscle-cell" caption="Smooth muscle cells - spindle-shaped with a single central nucleus, no striations. The contractile apparatus is anchored to dense bodies inside the cell and dense plaques on the membrane (functional equivalents of Z-discs in striated muscle)." />

### Structural features
- **Spindle-shaped** cells with central nucleus.
- **No sarcomeres** - actin + myosin still present but in a less ordered lattice, attached to **dense bodies** (functional equivalent of Z lines) and dense plaques on the membrane.
- **Caveolae** instead of T-tubules; less SR.
- Can be in **sheets** (visceral, single-unit - many gap junctions, syncytial behavior, spontaneous activity) or **multi-unit** (iris, vas deferens - each cell has its own innervation).

### Different regulation - Ca²⁺ + calmodulin + MLCK
1. Stimulus (NT, hormone, stretch) → ↑ cytosolic Ca²⁺ (extracellular via L-type + SR via IP3R).
2. Ca²⁺ binds **calmodulin** (not troponin - smooth muscle has no troponin).
3. Ca²⁺-calmodulin activates **myosin light chain kinase (MLCK)**.
4. MLCK phosphorylates **myosin regulatory light chain** → enables myosin head ATPase → contraction.
5. Relaxation = **MLC phosphatase (MLCP)** removes the phosphate.

**The Ca²⁺ sensitization pathway** - Rho kinase phosphorylates + inhibits MLCP → more contraction at the same Ca²⁺. Important in chronic vasoconstriction (HTN, pulmonary HTN).

### Latch state
Smooth muscle can hold contraction at low energy cost ("latch") - slow ATPase + dephosphorylation while still cross-bridged. Lets blood vessels stay constricted for hours without exhausting.

### Smooth muscle pharmacology
| Class | Site | Mechanism |
|---|---|---|
| **α1 agonists** (phenylephrine) | Gq → IP3 → Ca²⁺ ↑ → MLCK | Vasoconstriction |
| **β2 agonists** (albuterol) | Gs → cAMP → ↓ MLCK activity | Bronchodilation, uterine relaxation, vasodilation |
| **NO donors** (nitrates) | sGC → ↑ cGMP → activates MLCP → ↓ phosphorylation | Vasodilation (especially veins) |
| **PDE5 inhibitors** (sildenafil) | ↓ cGMP breakdown | Pulmonary + corpus cavernosum vasodilation |
| **L-type Ca²⁺ channel blockers** (amlodipine) | Block extracellular Ca²⁺ entry | Vasodilation |
| **Muscarinic antagonists** (atropine, ipratropium) | Block M3 | Bronchodilation, ↓ GI/bladder motility |

## Function reference - every key component

| Component | Function | Why it matters |
|---|---|---|
| **Troponin C** (skeletal + cardiac) | Ca²⁺ binding subunit | Cardiac troponin = MI biomarker |
| **Troponin I / T** | Inhibitor / tropomyosin binder | Same - cTnI most specific |
| **Tropomyosin** | Blocks myosin binding site on actin at rest | Moves out of the way when Ca²⁺ binds TnC |
| **DHPR** | Voltage sensor in T-tubule | Mechanical (skeletal) or chemical (cardiac) link to RyR |
| **RyR1** | Skeletal SR Ca²⁺ release | Malignant hyperthermia mutation |
| **RyR2** | Cardiac SR Ca²⁺ release | CPVT (catecholaminergic polymorphic VT) mutation |
| **SERCA** | Ca²⁺ pump back into SR | Phospholamban inhibition; PKA phosphorylates PLB → ↑ SERCA activity (β1 → faster relaxation, "lusitropy") |
| **Calmodulin** | Ca²⁺ sensor in smooth muscle (no troponin) | Activates MLCK |
| **MLCK / MLCP** | Smooth muscle on/off switches | Targets of cGMP/cAMP signaling |
| **Connexin 43** | Cardiac gap junctions | Loss → arrhythmias, heart failure |
| **Caveolin** | Smooth muscle plasma membrane microdomains | Loss → cardiomyopathy in some mutations |
| **Satellite cells** | Skeletal muscle stem cells | Source of post-injury regeneration; Pax7+ |
| **Myostatin** | Negative regulator of skeletal muscle mass | Mutation → "double-muscled" cattle, Belgian Blue; therapeutic target for muscle wasting |
| **Dystrophin-glycoprotein complex** | Links sarcomere to extracellular matrix | Lost in Duchenne MD → membrane fragility |

## Why this matters

<HighYield variant="boards">
- **Cardiac myocytes can't regenerate** - post-MI scar tissue is permanent → driver of heart failure.
- **Smooth muscle uniquely uses calmodulin + MLCK** (no troponin). Most cardiovascular drugs eventually act on this pathway.
- **Duchenne MD**: X-linked, frameshift mutation in dystrophin gene; Gowers sign + calf pseudohypertrophy + progressive proximal weakness; death by 30 from cardiopulmonary failure.
- **Becker MD**: in-frame deletion in dystrophin → partial protein → milder + later.
- **Myotonic dystrophy**: trinucleotide repeat (CTG in DMPK); myotonia + cataracts + frontal balding + cardiac conduction defects + insulin resistance.
- **Polymyositis vs dermatomyositis**: both proximal weakness; DM has skin findings (heliotrope rash, Gottron papules) + ↑ cancer risk. Anti-Jo-1 → antisynthetase syndrome.
- **Rhabdomyolysis** - muscle breakdown → CK release + myoglobinuria → AKI (heme-induced). Causes: crush injury, statins, drugs (cocaine, amphetamines), seizures, hyperthermia. Aggressive fluids; alkalinize urine.
- **β-blockers improve mortality in HFrEF** - slow HR, reduce O₂ demand, prevent remodeling. Don't start in acute decompensation.
- **Cardiac biomarkers timing**: Troponin rises 3–4 h, peaks 24 h, stays elevated 7–10 d. CK-MB rises 4–6 h, peaks 24 h, normalizes 48–72 h (useful for re-infarction).
</HighYield>
