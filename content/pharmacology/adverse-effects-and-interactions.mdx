## Adverse drug reactions (ADRs) - classification

| Type | Mechanism | Predictable? | Example |
|---|---|---|---|
| **A (augmented)** | Dose-related; exaggerated pharmacologic effect | Yes | Hypoglycemia from insulin; bleeding from warfarin |
| **B (bizarre)** | Idiosyncratic; immune-mediated or genetic | No | Penicillin anaphylaxis; halothane hepatitis; G6PD hemolysis |
| **C (chronic)** | Cumulative; with prolonged use | Yes | Iatrogenic Cushing from chronic steroids; tardive dyskinesia |
| **D (delayed)** | Long latency | Sometimes | DES carcinogenesis; clear cell vaginal adenocarcinoma |
| **E (end-of-use)** | Withdrawal syndromes | Yes | Rebound HTN after clonidine stop; benzodiazepine withdrawal |
| **F (failure)** | Unexpected drug failure | No | Failure of an antibiotic due to resistance |

## Adverse effects by organ system - "patterns to know"

### Hepatotoxicity
| Drug class / drug | Pattern |
|---|---|
| **Acetaminophen** | Dose-dependent; NAPQI saturates glutathione → hepatic necrosis. N-acetylcysteine antidote |
| **Isoniazid** | Idiosyncratic; check ALT, esp. with rifampin combination |
| **Methotrexate** | Chronic → fibrosis; monitor LFT, consider biopsy on cumulative dose |
| **Amiodarone** | Steatohepatitis-like; monitor LFT |
| **Statins** | Mild transaminase ↑; rarely true hepatitis |
| **Halothane** | Massive necrosis after second exposure (immune); avoid repeat |
| **Valproate** | Microvesicular steatosis; worst &lt;2 yrs old |
| **Tetracyclines (IV high-dose)** | Fatty liver in pregnancy |

### Nephrotoxicity
| Drug | Pattern |
|---|---|
| **Aminoglycosides** | Proximal tubular necrosis; check trough |
| **Vancomycin** | Tubular toxicity; trough 15–20 target |
| **Amphotericin B** | Tubular toxicity + hypokalemia/hypomagnesemia |
| **Cisplatin** | Proximal tubule + Mg wasting |
| **NSAIDs** | Pre-renal (afferent constriction); papillary necrosis in chronic abuse |
| **ACE-i/ARB** | Acute drop in GFR in bilateral RAS; hyperK⁺ |
| **Lithium** | Nephrogenic DI; chronic interstitial nephritis |
| **Contrast** | Tubular toxicity; hold metformin |

### Cardiotoxicity
| Drug | Pattern |
|---|---|
| **Doxorubicin / anthracyclines** | Dose-related dilated cardiomyopathy (cumulative >550 mg/m²); dexrazoxane protective |
| **Trastuzumab** | Reversible LVEF decline; not dose-related |
| **Cyclophosphamide** | Hemorrhagic myocarditis at high dose |
| **5-FU** | Coronary vasospasm |
| **Cocaine** | MI, dissection; **β-blocker contraindicated** (unopposed α) - use BZD + nitroglycerin |
| **Macrolides, fluoroquinolones, antipsychotics** | QT prolongation → torsades |
| **Anti-cancer TKIs (sunitinib)** | HF, HTN |

### Pulmonary toxicity
| Drug | Pattern |
|---|---|
| **Bleomycin** | Pulmonary fibrosis (dose-related; >400 U cumulative) |
| **Amiodarone** | Pulmonary fibrosis - check CXR + PFTs annually |
| **Methotrexate** | Hypersensitivity pneumonitis or fibrosis |
| **Nitrofurantoin** | Acute pneumonitis or chronic fibrosis |
| **Busulfan** | Fibrosis |
| **β-blockers** | Bronchospasm in asthmatics (avoid non-cardioselective) |

### Hematologic
| Drug | Pattern |
|---|---|
| **Chloramphenicol** | Aplastic anemia (idiosyncratic) + dose-related marrow suppression; gray baby in neonates |
| **Sulfonamides, dapsone, primaquine** | Hemolysis in G6PD deficiency |
| **Heparin** | HIT (PF4-antibody, day 5–10, paradoxical thrombosis) |
| **Linezolid, chloramphenicol** | Marrow suppression with prolonged use |
| **Methotrexate** | Pancytopenia |
| **Clozapine** | Agranulocytosis (monitor CBC weekly initially) |
| **Methimazole, PTU** | Agranulocytosis |
| **Ticlopidine** | TTP, neutropenia (replaced by clopidogrel) |

### Endocrine / metabolic
| Drug | Effect |
|---|---|
| **Thiazides** | ↑ Ca, ↑ glucose, ↑ uric acid, ↓ K, ↓ Na |
| **Loop diuretics** | ↓ K, ↓ Mg, ↓ Ca, ↑ uric acid, ototoxicity |
| **β-blockers** | Mask hypoglycemia in diabetics; bradycardia, fatigue |
| **SSRIs** | SIADH → hyponatremia (esp. elderly) |
| **Long-term steroids** | Cushing; osteoporosis; cataracts; growth retardation in kids |
| **Atypical antipsychotics** | Weight gain, metabolic syndrome (olanzapine > others) |
| **Tacrolimus, cyclosporine** | New-onset diabetes after transplant |

### Neurologic
| Drug | Effect |
|---|---|
| **Aminoglycosides, cisplatin, loop diuretics** | Ototoxicity |
| **Vincristine** | Peripheral neuropathy |
| **Isoniazid** | Peripheral neuropathy (B6 deficiency) - give pyridoxine |
| **Metronidazole** | Peripheral neuropathy with chronic use; disulfiram-like reaction with alcohol |
| **Antipsychotics (typical)** | EPS (acute dystonia, akathisia, parkinsonism), tardive dyskinesia, NMS |
| **Bupropion, clozapine, tramadol** | Seizure threshold ↓ |
| **Cyclophosphamide, ifosfamide** | Hemorrhagic cystitis (use **mesna**) |

### Dermatologic / connective tissue
| Drug | Effect |
|---|---|
| **Allopurinol, lamotrigine, carbamazepine, sulfa** | Stevens-Johnson / TEN; HLA-B*1502 in Asians |
| **Tetracycline (children &lt;8)** | Tooth discoloration, bone growth ↓ |
| **Fluoroquinolones** | Tendon rupture (esp. Achilles, elderly, steroids); arthropathy in kids |
| **Hydralazine, procainamide, isoniazid** | Drug-induced lupus (slow acetylators) |
| **Long-term steroids** | Skin thinning, striae, easy bruising, delayed wound healing |
| **Minocycline** | Skin/teeth pigmentation |

## Five "syndromes" of drug toxicity to recognize

| Syndrome | Cause | Features |
|---|---|---|
| **Serotonin syndrome** | SSRIs + MAOI, tramadol, linezolid, triptans, ondansetron, ecstasy | **HARMED**: Hyperthermia, autonomic instability (↑ HR, ↑ BP, mydriasis), rigidity (lower>upper), myoclonus, encephalopathy, **diarrhea**, hyperreflexia. **Cyproheptadine** rescue. |
| **NMS (neuroleptic malignant)** | D2-antagonists (haloperidol, antipsychotics) or sudden dopaminergic withdrawal | **FALTER**: Fever, autonomic instability, leukocytosis, **rigidity** (upper>lower, "lead pipe"), elevated CK, rhabdo. **Dantrolene + bromocriptine**. |
| **Malignant hyperthermia** | Volatile anesthetics + succinylcholine, RYR1 mutation | Hypercarbia (early!), masseter rigidity, hyperthermia, rhabdo, hyperK. **Dantrolene**. |
| **Anticholinergic toxidrome** | TCAs, antihistamines, antipsychotics, scopolamine | "Hot as Hades, blind as a bat, dry as a bone, red as a beet, mad as a hatter, full as a flask." Treat supportively; **physostigmine** for severe (avoid in TCA QRS-widening). |
| **Cholinergic toxidrome (SLUDGE)** | Organophosphate poisoning, neostigmine excess | Salivation, lacrimation, urination, diarrhea, GI cramps, emesis + miosis, bradycardia, bronchospasm. **Atropine + pralidoxime**. |

## Drug-drug interaction patterns

| Interaction | Mechanism | Example |
|---|---|---|
| **CYP3A4 inhibition** | ↑ substrate level | Statin + azole = myopathy |
| **CYP3A4 induction** | ↓ substrate level | Rifampin + OC = pregnancy |
| **Protein-binding displacement** | ↑ free drug | Sulfonamide + warfarin (clinically less important than thought, but free-fraction matters in liver disease) |
| **Renal transport competition** | ↓ excretion | Probenecid + penicillin |
| **Pharmacodynamic additive** | Both depress CNS | Alcohol + benzodiazepine = respiratory depression |
| **Pharmacodynamic antagonism** | Counters effect | NSAIDs blunt antihypertensive of ACE-i |
| **QT additive** | Multiple QT-prolonging drugs | Azithromycin + ondansetron + haloperidol = torsades |

## Drug-food + drug-supplement interactions

- **Grapefruit juice** - inhibits intestinal CYP3A4 + P-glycoprotein → ↑ levels of statins (esp. simvastatin, lovastatin), amiodarone, CCBs (felodipine), cyclosporine. Effect lasts >24 h.
- **Tyramine + MAOIs** - aged cheese, cured meats, wine → hypertensive crisis.
- **Vitamin K** - greens reduce warfarin effect; consistent intake matters more than absolute amount.
- **Calcium / dairy** - chelates tetracyclines, fluoroquinolones, levothyroxine, iron, bisphosphonates → ↓ absorption.
- **St. John's wort** - CYP3A4 + P-gp inducer → ↓ OC, cyclosporine, antiretrovirals, warfarin.

## Beers list / drugs to avoid in older adults

Common offenders: long-acting benzodiazepines (diazepam, flurazepam), first-generation antihistamines (diphenhydramine), anticholinergics, NSAIDs, muscle relaxants (cyclobenzaprine), TCAs (amitriptyline > nortriptyline), glyburide (severe hypoglycemia in elderly).

## Pregnancy risk - the "TERATOGENS"

| Drug | Effect |
|---|---|
| **Warfarin** | Fetal warfarin syndrome (nasal hypoplasia, stippled epiphyses); use heparin instead |
| **ACE-i / ARBs** | Renal dysgenesis, oligohydramnios (2nd/3rd trim) |
| **Methotrexate, misoprostol** | Abortifacient |
| **Lithium** | Ebstein anomaly |
| **Valproate, carbamazepine** | Neural tube defects; folate doesn't fully prevent |
| **Phenytoin** | Fetal hydantoin syndrome (cleft lip/palate, digital hypoplasia) |
| **Isotretinoin** | Severe craniofacial + cardiac defects - iPLEDGE program |
| **Tetracycline** | Tooth/bone discoloration |
| **Aminoglycosides** | Cranial nerve VIII |
| **Fluoroquinolones** | Cartilage damage |
| **Thalidomide** | Phocomelia |
| **DES** | Vaginal clear-cell adenocarcinoma in daughters |
| **Alcohol** | Fetal alcohol syndrome |
| **Smoking / cocaine** | Placental abruption, growth restriction |

<HighYield variant="boards">
- Distinguish serotonin syndrome (myoclonus, hyperreflexia, **clonus**, diarrhea) from NMS (lead-pipe rigidity, slower onset, hyporeflexia, fewer GI symptoms). Time course of recent serotonergic drug change favors serotonin syndrome.
- "Drug that requires monitoring before each dose": clozapine (ANC), warfarin (INR), lithium (Li level + creatinine), aminoglycosides (trough), vancomycin (trough), digoxin (level + K+).
- **Black box warnings** to remember: typical/atypical antipsychotics → ↑ mortality in dementia; SSRIs → ↑ suicidality in adolescents/young adults; fluoroquinolones → tendon rupture, aortic dissection; rosiglitazone → cardiovascular events.
- N-acetylcysteine for acetaminophen overdose: ideally within 8 h. Dosed via Rumack-Matthew nomogram or 21-h IV protocol.
</HighYield>
