## α-blockers

| Drug | Selectivity | Use |
|---|---|---|
| **Phenoxybenzamine** | Non-selective (α1 = α2), **irreversible** | Pheochromocytoma preop (irreversible block survives catecholamine surge) |
| **Phentolamine** | Non-selective, reversible | Hypertensive crisis from MAOI + tyramine; α-agonist extravasation reversal |
| **Prazosin** | α1-selective | HTN, BPH, **PTSD-related nightmares** |
| **Terazosin, Doxazosin** | α1-selective long-acting | HTN, BPH |
| **Tamsulosin, Silodosin, Alfuzosin** | α1A-selective (prostate) | BPH (minimal BP effect; selective for prostate α1A) |

### Side effects
- **First-dose orthostatic hypotension** - the patient stands up, faints. Start at bedtime, low dose, titrate up.
- **Floppy iris syndrome** during cataract surgery (tamsulosin) - stop weeks before.
- **Reflex tachycardia** - α-block lowers BP → baroreceptor reflex → ↑ HR via vagal withdrawal + sympathetic outflow. Less with α2 preserved (selective α1 antagonists).

### Pheochromocytoma preop
1. α-block first (phenoxybenzamine 10–20 mg BID, titrate up) for **10–14 days**.
2. Liberalize salt + fluids (the expanded vascular bed needs filling).
3. THEN add β-block if tachycardia (only after α is established).
4. Surgery: have phentolamine + sodium nitroprusside ready for intraoperative HTN spikes during tumor manipulation.

**Why never β-block first**: β2-mediated vasodilation is lost → unopposed α1 vasoconstriction → catastrophic hypertensive crisis.

## β-blockers

### Generations + selectivity

| Generation | Drugs | Properties |
|---|---|---|
| **1st gen (non-selective)** | Propranolol, Timolol, Nadolol, Sotalol, Pindolol | β1 = β2 block |
| **2nd gen (β1-selective)** | Metoprolol, Atenolol, Bisoprolol, Esmolol, **Acebutolol** | β1 >> β2 (still some β2 at high doses) |
| **3rd gen (vasodilating)** | Carvedilol, Labetalol (also α1-block); Nebivolol (NO release) | Lower SVR + favorable in HF |

**Mnemonic**: β1-selective drugs come alphabetically A–M (Acebutolol, Atenolol, Bisoprolol, Esmolol, Metoprolol). Non-selective from N–Z (Nadolol, Pindolol, Propranolol, Sotalol, Timolol).

### Pharmacology by drug

| Drug | Half-life | Notes |
|---|---|---|
| **Propranolol** | 4 h | Crosses BBB → tremor, migraine, performance anxiety, hyperthyroid storm |
| **Metoprolol tartrate** | 3–4 h | BID dosing |
| **Metoprolol succinate** | XR, 24 h | Daily; HF approved |
| **Atenolol** | 6–9 h, renally cleared | Avoid in renal failure |
| **Esmolol** | **9 min** | IV drip; rapid titration in OR / ICU |
| **Carvedilol** | 7 h | β + α1 block → vasodilation; HF, HTN |
| **Labetalol** | 6 h | β + α1; pregnancy HTN, hypertensive emergency |
| **Nebivolol** | 12 h | β1 + NO release; less metabolic effect |
| **Bisoprolol** | 10 h | HF approved, daily |
| **Sotalol** | 12 h | Class III antiarrhythmic (K-channel block) + non-selective β |
| **Pindolol, Acebutolol** | ISA (intrinsic sympathomimetic activity) | Partial agonists - less bradycardia, but NOT for post-MI |

### Cardiovascular effects of β-block
- **β1 block** → ↓ HR (chronotropic), ↓ contractility (inotropic), ↓ AV conduction (dromotropic), ↓ renin (kidney).
- **β2 block** → bronchoconstriction (avoid in asthma), vasoconstriction (cold extremities, Raynaud), ↑ uterine tone, masks hypoglycemia signs (tremor, tachycardia - sweating still present, helpful in diabetic).

### Indications

| Use | Notes |
|---|---|
| **HTN** | Not first-line for uncomplicated (per JNC 8); use ACE-i, ARB, CCB, thiazide |
| **HF (with rEF)** | **Mortality benefit**: carvedilol, metoprolol succinate, bisoprolol. Start LOW and go SLOW |
| **Post-MI** | Mortality benefit for ~2 years (esp. metoprolol, carvedilol) |
| **Stable angina** | ↓ myocardial O₂ demand |
| **SVT, A-fib rate control** | β1-mediated AV node slowing |
| **Hyperthyroidism / thyroid storm** | Propranolol (also blocks T4→T3 conversion peripherally) |
| **Migraine prophylaxis** | Propranolol, metoprolol |
| **Essential tremor** | Propranolol |
| **Performance anxiety** | Propranolol low dose pre-event |
| **Glaucoma** | Timolol drops (↓ aqueous humor production) |
| **Pheochromocytoma** | After α-block established |
| **Long QT, torsades** | β1-block ↓ catecholamine-triggered arrhythmias |

### Contraindications + warnings
- **Severe asthma / bronchospasm** - avoid non-selective; cardio-selective like metoprolol acceptable if needed.
- **Severe bradycardia, AV block (>1st degree without pacemaker)** - obvious.
- **Acute decompensated HF** - hold until compensated (β-block helps chronic but acutely lowers CO).
- **Cocaine-induced chest pain** - unopposed α (controversial; some say labetalol acceptable).
- **Diabetes** - mask tachycardia/tremor of hypoglycemia (sweating preserved). Cardio-selective preferred.
- **Pregnancy** - labetalol preferred. Atenolol associated with IUGR if used early.

### Toxicity + reversal
β-blocker overdose: bradycardia, hypotension, hypoglycemia, bronchospasm, seizures (esp. propranolol). Treatment:
1. **Glucagon** (Gs receptor → ↑ cAMP, bypasses β-receptor block).
2. **Atropine** (if bradycardia).
3. **IV fluids + vasopressors** (high-dose).
4. **High-dose insulin + glucose** ("HIE") for shock - improves myocardial substrate use.
5. **Intralipid** emulsion for lipid-soluble propranolol toxicity.
6. **Pacing, ECMO** in refractory.

## Combined α + β block

**Carvedilol**, **labetalol**: useful when both vasoconstriction (α1) and ↓ CO (β1) wanted. Pregnancy HTN, hypertensive emergencies, HF (carvedilol). Less reflex tachycardia than pure α-block.

## Sotalol - the antiarrhythmic β-blocker

Class III antiarrhythmic (K+ channel block prolongs QT) + non-selective β-block. Used for VT, A-fib rhythm control. **Watch QTc** - torsades risk. Adjust dose for renal function.

<Clinical>
**Holiday Heart Syndrome**: binge alcohol → A-fib in a normal heart. Rate-control with metoprolol or diltiazem; spontaneous conversion common in 24 h.

**Thyroid storm**: propranolol IV - blocks β1 (rate) + peripheral T4→T3 conversion + adrenergic symptoms. Often combined with PTU/methimazole + steroids + cooling.

**Migraine prophylaxis decisions**: propranolol (β-block), topiramate, amitriptyline, CGRP antagonists (newest). Choose based on comorbidity - propranolol best for migraine + HTN + essential tremor; topiramate avoid in cognitive concerns; CGRP if all others failed.

**Carvedilol vs metoprolol succinate in HF**: both have RCT-proven mortality benefit. Carvedilol's α-block produces more orthostasis but more peripheral arterial dilation. Choose based on tolerability + comorbidity.
</Clinical>

- Esmolol = short-acting IV → titratable for intraoperative HTN, peri-intubation.
- Carvedilol, metoprolol succinate, bisoprolol = the three β-blockers with mortality benefit in **HFrEF**.
- α-block before β-block in pheochromocytoma. Always.
- Sudden discontinuation → rebound HTN + tachycardia + worsening angina. Taper.
- Selective α1-blockers (tamsulosin) for BPH have minimal BP effect because they spare α1B in vasculature.
- Prazosin for **PTSD nightmares** is a classic high-yield indication.
