## Principles of antimicrobial selection

1. **Identify the pathogen** when possible (culture before empirics ideally).
2. **Source control** - drain abscesses, remove catheters/foreign bodies, debride.
3. **Empiric coverage** based on likely organisms by site + risk factors.
4. **De-escalate** when sensitivities return.
5. **Duration** - shortest effective course (most infections 5-7 days; specific guidelines vary).
6. **Bactericidal vs bacteriostatic** matters in: endocarditis, meningitis, neutropenia.

### Bactericidal vs bacteriostatic - high-yield matrix

| Bactericidal | Bacteriostatic |
|---|---|
| β-lactams | Tetracyclines |
| Vancomycin | Macrolides |
| Aminoglycosides | Clindamycin |
| Fluoroquinolones | Linezolid (mostly) |
| Metronidazole | Sulfonamides + trimethoprim |
| Daptomycin | Chloramphenicol |
| Rifampin | |

Mnemonic for bacteriostatic: **"We're ECSTaTiC about bacteriostatics"**: Erythromycin/macrolides, Clindamycin, Sulfa, Tetracycline, Trimethoprim, Chloramphenicol.

### Mechanisms by drug class

| Mechanism | Class |
|---|---|
| **Cell wall synthesis** | β-lactams, vancomycin, bacitracin, daptomycin (mechanism differs - membrane) |
| **30S ribosome** | Aminoglycosides, tetracyclines |
| **50S ribosome** | Macrolides, clindamycin, chloramphenicol, linezolid, streptogramins |
| **DNA gyrase / topoisomerase** | Fluoroquinolones |
| **DNA damage** | Metronidazole |
| **RNA polymerase** | Rifampin |
| **Folate metabolism** | TMP-SMX, sulfa, dapsone, pyrimethamine |

## β-lactams - mechanism

Bind penicillin-binding proteins (transpeptidases) → ↓ cross-linking of peptidoglycan → cell wall instability → lysis. **Bactericidal** in dividing organisms.

Resistance mechanisms:
1. β-lactamase enzymes (hydrolyze ring).
2. Altered PBPs (MRSA, PRSP).
3. ↓ porins (Pseudomonas, Enterobacter).
4. Efflux pumps.

### Penicillins by spectrum

| Subclass | Drugs | Coverage |
|---|---|---|
| **Natural** | Penicillin G (IV), V (PO) | Streptococci, syphilis (T. pallidum), Listeria, anaerobes above diaphragm |
| **Antistaphylococcal** (penicillinase-resistant) | Nafcillin, Oxacillin, Dicloxacillin, Methicillin | MSSA (not MRSA) |
| **Aminopenicillins** | Amoxicillin, Ampicillin | + Listeria, Enterococcus, H. influenzae, E. coli (older) |
| **Antipseudomonal** | Piperacillin, Ticarcillin (often with tazobactam/clavulanate) | + Pseudomonas + most Gram-negatives + anaerobes (when combined with β-lactamase inhibitor) |

### β-lactamase inhibitors

**Clavulanate, Sulbactam, Tazobactam, Avibactam, Vaborbactam, Relebactam**

Restore activity against β-lactamase producers when combined:
- **Amoxicillin-clavulanate** (Augmentin) - upper resp, sinusitis, otitis media, bites.
- **Ampicillin-sulbactam** (Unasyn) - intra-abdominal, pelvic, head/neck.
- **Piperacillin-tazobactam** (Zosyn) - sepsis, intra-abdominal, hospital-acquired pneumonia.
- **Ceftolozane-tazobactam, Ceftazidime-avibactam** - MDR Gram-negatives, ESBL.
- **Meropenem-vaborbactam, Imipenem-relebactam** - KPC carbapenemase.

### Penicillin side effects

- **Allergy** - urticaria → anaphylaxis. True IgE incidence ~1%. Penicillin allergy testing now widely available - 90% of patients who report allergy aren't truly allergic.
- **Rash with EBV mononucleosis** when given ampicillin - not a true allergy.
- **Interstitial nephritis** - methicillin classic; can occur with any.
- **Hemolysis** (Coombs-positive) - high-dose penicillin.
- **Neurotoxicity** - high doses, esp. with renal failure → seizures.
- **Diarrhea** - dose-dependent; C. diff risk especially with amoxicillin-clavulanate.

### Cephalosporins by generation

| Gen | Drugs | Coverage |
|---|---|---|
| **1st** | Cefazolin (IV), Cephalexin (PO) | Gram+ (esp. MSSA, strep); few Gram- (E. coli, Klebsiella, Proteus = "PEcK"). Surgical prophylaxis |
| **2nd** | Cefuroxime, Cefoxitin, Cefotetan | + H. influenzae, Enterobacter, Neisseria. Cefoxitin + cefotetan have **anaerobic** coverage (intra-abdominal). "HEN PEcK + HiBaNS" |
| **3rd** | Ceftriaxone, Cefotaxime, Ceftazidime | Broad Gram-, less Gram+. Ceftriaxone = meningitis, gonorrhea, Lyme, pneumonia, pyelonephritis. **Ceftazidime** = Pseudomonas |
| **4th** | Cefepime | Broad - Pseudomonas + many Gram- + Gram+ |
| **5th** | Ceftaroline | Anti-MRSA + Gram-negatives (not Pseudomonas) |
| **Anti-MDR** | Ceftolozane-taz, Ceftazidime-avib, Cefiderocol | MDR Gram-negatives, ESBL, carbapenemase (avibactam) |

### Cephalosporin specifics

- **Cefazolin** = surgical prophylaxis workhorse.
- **Ceftriaxone** = meningitis (good CSF penetration); also pneumonia, gonorrhea, Lyme, typhoid. AVOID in **neonates** (displaces bilirubin from albumin → kernicterus) and not with calcium-containing IV solutions in neonates.
- **Ceftazidime, Cefepime** = Pseudomonas.
- **Cefepime** can cause **neurotoxicity** (encephalopathy, status) - esp. renal failure.
- **Disulfiram-like reaction**: cefotetan, cefoxitin - avoid alcohol.

### Carbapenems

**Imipenem, Meropenem, Ertapenem, Doripenem**

**Spectrum**: very broad - Gram-positives + Gram-negatives + anaerobes + ESBL-producing Enterobacterales. Most powerful β-lactam class.

- **Imipenem** must be combined with **cilastatin** (inhibits renal dehydropeptidase that would inactivate imipenem). **Seizure risk** especially with renal failure.
- **Meropenem** - less seizure risk; preferred in CNS infections.
- **Ertapenem** - no Pseudomonas coverage; once-daily; useful for outpatient parenteral.
- **Doripenem** - rarely used.

**Side effects**: GI, rash, **seizures** (imipenem), C. diff.

**Reserve** for serious infections to prevent resistance (esp. CRE - carbapenem-resistant Enterobacterales).

### Aztreonam

**Monobactam** - only Gram-negative + Pseudomonas coverage. **No cross-reactivity with penicillin allergy** (different ring). Use in:
- Penicillin/cephalosporin allergic with Gram-negative infection.
- Avoid aminoglycoside (nephro/ototoxicity).

## Vancomycin

**Mechanism**: binds **D-Ala-D-Ala** terminus of peptidoglycan precursor → ↓ cross-linking. Distinct site from β-lactams; no cross-resistance.

**Spectrum**: Gram-positives - MRSA, MSSA, streptococci, enterococci (most), C. diff (PO route only).

**Pharmacology**:
- IV for systemic infections; PO for C. diff (not absorbed → stays in gut).
- Renally cleared - dose adjust per nomogram, target **AUC/MIC > 400** (newer) or trough 15-20 (older).

**Side effects**:
- **Red man syndrome** - histamine release from rapid infusion; itchy red rash. NOT an allergy - slow the infusion + pretreat with antihistamine.
- **Nephrotoxicity** - ↑ with high troughs + aminoglycoside + diuretics + advanced age.
- **Ototoxicity** - rare; risk with high levels.
- **DRESS, SJS** - rare.
- **Thrombophlebitis** - PICC preferred for prolonged courses.

**Resistance**: **VRE** (vancomycin-resistant enterococcus) - D-Ala-D-Lac substitution. **VRSA** - rare but emerging.

## Lipoglycopeptides

**Telavancin, Dalbavancin, Oritavancin** - vancomycin analogs with longer t½.

- **Dalbavancin** - weekly IV; for skin/soft tissue infections.
- **Oritavancin** - single dose; cellulitis (avoid concurrent warfarin).
- **Telavancin** - daily; covers MRSA + similar to vanco.

## Daptomycin

**Mechanism**: cyclic lipopeptide; inserts into Gram-positive membrane → depolarization → death. Bactericidal.

**Spectrum**: MRSA, VRE, MSSA. Not respiratory (inactivated by surfactant - **don't use for pneumonia**).

**Use**: complicated bacteremia, endocarditis (right-sided), skin/soft tissue.

**Side effects**: **myopathy** (check CK weekly; hold statin during therapy), **eosinophilic pneumonia** (rare), peripheral neuropathy.

## Bacitracin

Polypeptide; cell wall synthesis. Topical only (nephrotoxic systemically). Skin infections, ophthalmic.

## Polymyxins

**Polymyxin B, Colistin (Polymyxin E)** - disrupt outer membrane of Gram-negatives. Reserved for **MDR Gram-negatives** (KPC, NDM carbapenemase).

**Side effects**: **nephrotoxicity** (significant), neurotoxicity.

## Empiric coverage by site (quick reference)

| Infection | Empiric |
|---|---|
| **Community-acquired pneumonia (CAP)** | Outpatient: amoxicillin or doxycycline. Hospital: ceftriaxone + azithromycin (or fluoroquinolone) |
| **Hospital-acquired / VAP** | Piperacillin-tazobactam OR cefepime OR meropenem + vancomycin ± aminoglycoside (if Pseudomonas concern) |
| **Meningitis** (adult) | Ceftriaxone + vancomycin + dexamethasone ± ampicillin (Listeria if >50 or immunocompromised) |
| **UTI - uncomplicated** | Nitrofurantoin × 5 d OR TMP-SMX × 3 d OR fosfomycin × 1 dose |
| **Pyelonephritis** | Ciprofloxacin or ceftriaxone IV then PO |
| **Cellulitis** | Cephalexin (no MRSA risk) or TMP-SMX/doxycycline + cephalexin (MRSA risk) |
| **Severe skin / nec fasc** | Piperacillin-tazobactam + vancomycin + clindamycin (toxin suppression) |
| **Intra-abdominal** | Piperacillin-tazobactam OR ceftriaxone + metronidazole |
| **Diabetic foot - severe** | Piperacillin-tazobactam ± vancomycin |
| **Sepsis - unknown source** | Vancomycin + piperacillin-tazobactam (or cefepime, or meropenem) within 1 h |
| **Endocarditis - native valve, MSSA** | Nafcillin/oxacillin + gentamicin (synergy, brief) |
| **Endocarditis - MRSA** | Vancomycin + gentamicin (briefly) |
| **C. difficile** | Vancomycin PO or fidaxomicin |
| **Gonorrhea** | Ceftriaxone IM + doxycycline (if not pregnant - chlamydia coverage) |
| **Syphilis** | Penicillin G benzathine IM |
| **Lyme** | Doxycycline (or amoxicillin in pregnancy/peds) |
| **Tonsillitis (strep)** | Penicillin V or amoxicillin |

## Penicillin allergy - what to do

- **History only "rash as a child"** - often not true IgE; consider testing.
- **Anaphylaxis history** - avoid all β-lactams traditionally; modern data shows ~2% cross-reactivity with cephalosporins (vs old 10%). Test if confirmation needed.
- **Severe (SJS/TEN, DRESS, AGEP, serum sickness)** - avoid all β-lactams forever.
- **Alternatives by infection**: macrolide (strep), TMP-SMX (skin/UTI), doxycycline (skin, atypicals), aztreonam (Gram-neg), vancomycin (Gram+), fluoroquinolone (broad).

<Clinical>
**Sepsis bundle (1 hour)**: blood cultures × 2 + lactate + empiric antibiotics within 1 h + IV fluids 30 mL/kg crystalloid + vasopressors if MAP &lt;65 despite fluids.

**Vancomycin dosing**: 15-20 mg/kg IV q8-12h (renal function dependent). Trough goal 15-20 for serious infections (meningitis, pneumonia, endocarditis, bacteremia). AUC-guided dosing now preferred where available.

**MRSA hospital bacteremia**: vancomycin first-line; if MIC creep (>1.5) or treatment failure → daptomycin (not pneumonia) or ceftaroline.

**C. diff treatment**: vancomycin PO 125 mg QID × 10 days OR fidaxomicin PO 200 mg BID × 10 days (fewer recurrences). Metronidazole no longer first-line.

**Penicillin allergy in pregnant patient with syphilis**: **desensitize** to penicillin. It's the only effective treatment for fetal transmission.
</Clinical>
